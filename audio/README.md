# Orbit — IMlearning

Оригинальная инструментальная композиция, синтезированная для IMlearning.
Внешние записи, семплы и произведения других авторов не использованы.

`orbit.wav`: моно PCM, 22050 Гц, 16 бит, 38,4 секунды; бесшовный цикл.
Исходник аранжировки и синтеза: `scripts/compose_ambient.py` (NumPy).
Проверка воспроизводимости: запустить скрипт и сравнить `git diff -- audio/orbit.wav`.

Воспроизведение включается пользователем. Плеер сохраняет громкость и выбор
в `imlearning-sound-v1`; после перезагрузки страницы требуется нажатие для
продолжения. Переходы внутри сайта сохраняют воспроизведение. Удаление локальных
данных сбрасывает настройки плеера. Учебная резервная копия не содержит музыку
или настройки звука.

Тик интерфейса синтезируется в `sound.js` через Web Audio: короткий импульс шума
длительностью 26 мс с полосовым фильтром. Он не требует загрузки файла и работает
отдельно от музыки. После первого клика/нажатия клавиши браузер разблокирует звук;
наведение на кнопки, ссылки и учебные карточки воспроизводит тик. Перемещение между
дочерними элементами одного блока не повторяет звук; частота ограничена одним
тиком за 70 мс. Сенсорные касания и отключённые кнопки не озвучиваются.

Выключатель тика и отдельная громкость доступны в панели звука. Их значения
добавлены к `imlearning-sound-v1`; прежние настройки музыки совместимы. Проверка:
`python tests/browser_ticks.py` при запущенном локальном сервере.
