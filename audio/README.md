# Orbit — IMlearning

Оригинальная инструментальная композиция, синтезированная для IMlearning.
Внешние записи, семплы и произведения других авторов не использованы.

`orbit.wav`: моно PCM, 22050 Гц, 16 бит, 38,4 секунды; бесшовный цикл.
Исходник аранжировки и синтеза: `scripts/compose_ambient.py` (NumPy).
Проверка воспроизводимости: запустить скрипт и сравнить `git diff -- audio/orbit.wav`.

Воспроизведение включается пользователем. Плеер сохраняет громкость и выбор
в `imlearning-sound-v1`; после перезагрузки страницы требуется нажатие для
продолжения. Переходы внутри сайта сохраняют воспроизведение. Удаление локальных
данных сбрасывает настройки плеера. Учебная резервная копия не содержит музыку
или настройки звука.
