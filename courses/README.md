## Жергілікті іске қосу / Локальный запуск

Бөлек Python ортасын қолдан. Репозиторий түбірінен / Используй отдельное Python-окружение. Из корня репозитория:

```sh
python -m venv .venv
# Активируй окружение / Ортаны белсендір
python -m pip install -r courses/requirements.txt
python -m jupyterlab --notebook-dir courses
```

Colab-қа арналған Drive ұяшықтары жергілікті Jupyter ішінде жұмыс істемейді: жергілікті файл жолын қолдан. Кейбір жұмыстарда сыртқы CSV/TXT немесе интернет қажет; әр бөлімдегі ескертулерді оқы.

Ячейки Google Drive для Colab не запускаются в обычном Jupyter: используй локальные пути. Части работ требуют внешних CSV/TXT или интернета; ограничения перечислены в разделах. Автоматически чужие блокноты не выполнялись: проверены JSON-структура, число ячеек и побайтовое совпадение с исходниками.
