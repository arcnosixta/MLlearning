## Орындау / Запуск

Google Colab ішінде «File → Upload notebook» арқылы немесе JupyterLab-та аш. Ұяшықтарды ретімен орында; бастапқы сақталған нәтижелер жаңа іске қосуды алмастырмайды.

Открой блокнот в Google Colab через «File → Upload notebook» или в JupyterLab. Выполняй ячейки последовательно; сохранённые исходные выводы не заменяют новый запуск.

Colab ұяшықтарын жоғарыдан төмен қарай орында.

Выполняй ячейки Colab сверху вниз.
