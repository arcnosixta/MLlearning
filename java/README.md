# Java · 14 недель / Java · 14 апта

Семестровый учебный маршрут IMlearning для подготовки к университетским контрольным. Первые семь недель доводят до `abstract`; вторые семь расширяют курс до проекта. План нужно сопоставить с фактическим силлабусом преподавателя. Тесты — тренировочные, результат не является официальной оценкой.

Университет бақылауына арналған IMlearning семестрлік бағыты. Алғашқы жеті апта `abstract` тақырыбына жеткізеді, келесі жеті апта жобамен аяқталады. Жоспарды оқытушының нақты силлабусымен салыстыр. Тест нәтижесі ресми баға емес.

На неделю предложены 2 часа теории, 2 часа практики и 1 час повторения. Это ориентир, а не обещание длительности. Каждая неделя содержит 3 теоретических раздела, компилируемый пример, самостоятельную задачу, разбор частой ошибки, терминал коротких ответов, 6 вопросов и заметки.

Аптасына 2 сағат теория, 2 сағат тәжірибе, 1 сағат қайталау ұсынылады. Бұл — бағдар. Әр аптада үш теория бөлімі, компиляцияланатын мысал, өздік жұмыс, жиі қате талдауы, қысқа жауап терминалы, алты сұрақ және жазбалар бар.

## Практика / Тәжірибе

Установи JDK 17+ и выбери папку одной недели. Каждый пример независим и имеет класс `Main`:

JDK 17+ орнатып, бір аптаның каталогын таңда. Әр мысал тәуелсіз, класс атауы `Main`:

```sh
cd java/examples/07
javac Main.java
java Main
```

Терминал на сайте проверяет короткие ответы/команды по условию задачи, учитывает регистр и не исполняет произвольный Java-код или команды ОС. Полные программы скачиваются и запускаются локально. Это явно указано рядом с полем ввода.

Сайт терминалы тапсырма бойынша қысқа жауаптар мен пәрмендерді тексереді, регистрді ескереді. Ол еркін Java кодын не ОЖ пәрменін орындамайды. Толық бағдарламаны жүктеп алып, жергілікті орында.

## Контроли / Бақылаулар

- РК-1: 30 вопросов, недели 1–7, 45 минут.
- РК-2: 30 вопросов, недели 8–14, 45 минут.
- Сессия / сессия: 60 вопросов, недели 1–14, 90 минут.

В банке 84 уникальных вопроса: по три теоретических и три на чтение кода на каждую неделю. Выборка балансируется по неделям, порядок перемешивается с сохраняемым seed. Поэтому вопросы могут повторяться между тренировочными попытками. Ответы на вопросы недели доступны сразу, на экзамене — после завершения. Пропуск считается неверным ответом. После результата показаны правильные ответы, объяснения и ссылки на слабые темы.

Банкте 84 бірегей сұрақ бар: әр аптаға үш теориялық және үш код сұрағы. Таңдау апталар бойынша теңестіріліп, реттілік сақталатын seed-пен араласады. Жаттығу талпыныстарында сұрақ қайталануы мүмкін. Апталық жауап бірден, емтихан жауабы аяқтағаннан кейін ашылады. Бос жауап қате саналады.

Таймер основан на абсолютном времени, перезагрузка не даёт новые 45/90 минут. Если уйти со страницы, просроченная попытка завершается при возвращении. Это клиентский тренажёр: время устройства и локальные ответы не защищены от намеренного изменения. Он не предназначен для проведения официального контролируемого экзамена.

Таймер абсолют уақытты қолданады, қайта жүктеу уақыт қоспайды. Басқа бетке кеткенде мерзімі біткен талпыныс оралғанда аяқталады. Бұл клиенттік жаттығу құралы, ресми бақылаулы емтихан жүйесі емес.

## Данные / Деректер

`MLStore` сохраняет Java-данные отдельно в поле `java` существующего объекта `mllearning-data-v1`. Старые ML-данные и резервные копии версии 1 совместимы. Сохраняются недели, заметки, ответы, успехи терминала, одна текущая попытка и последние 10 завершённых. Экспорт/импорт и полное удаление находятся в «Мои данные».

Java деректері `mllearning-data-v1` объектісінің `java` өрісінде бөлек сақталады. Бұрынғы ML деректері мен 1-нұсқа көшірмелері үйлесімді. Апталар, жазбалар, жауаптар, терминал нәтижесі, бір белсенді және соңғы 10 аяқталған талпыныс сақталады.

## Проверка / Тексеру

```sh
python scripts/build.py
python tests/verify_java.py
node tests/java_core_check.js
# При запущенном сервере dist/ / dist сервері іске қосылғанда:

```

`verify_java.py` компилирует 14 полных примеров и 42 кодовые задачи через `javac --release 17`, запускает и сверяет фактический вывод. Браузерные проверки охватывают RU/ҚАЗ, мобильную вёрстку, таймер, восстановление попыток, подсчёт результата и совместимость резервных копий.

Материалы опираются на официальные [Dev.java](https://dev.java/learn/) и [Java Tutorials: abstract classes](https://docs.oracle.com/javase/tutorial/java/IandI/abstract.html). Ссылки по темам находятся в каждой неделе. В примерах не используются preview-функции новых версий Java.
