# JDBC, SQL, транзакциялар және DAO

Мақсат: параметрлі сұрауды орындап, транзакция шекарасын белгілеу.

## JDBC келісімі

JDBC — API, дайын дерекқор емес. Connection сеансты, PreparedStatement команданы, ResultSet нәтиже курсорын береді. Нақты базаға драйвер және JDBC URL қажет. DataSource қосылым алуды бөледі. Параметр индекстері 1-ден басталады. `WHERE id=?` пен setLong қолдан: мәтін конкатенациясы SQL-инъекциясына жол ашады. Параметр кесте атауын алмастырмайды.

autoCommit қосулы болса, командалар бөлек бекітіледі. Бір операциядағы бірнеше өзгеріске autoCommit=false, соңында commit, қатеде rollback керек. Rollback қатесі бастапқы себепті жасырмауы тиіс. DAO SQL-ды жасырады, сервис бүкіл транзакцияны анықтайды. SQLException-ды «жазба жоқ» нәтижесіне айналдырма.

ResultSet бастапқыда бірінші жолдың алдында тұрады, next арқылы жылжиды. Ресурстарды try-with-resources жап. SQL NULL үшін wasNull не getObject таңда. Metadata бағандар мен база мүмкіндіктерін сипаттайды; batch және stored procedure келісімін СУБД-мен сәйкестендір.
