# Типтер, операторлар және дәл есептеу

Мақсат: дерек мағынасына сай тип таңдап, түрлендіру мен толып кетуді түсіндіру.

## Типтер және мәндер

Сегіз примитив бар: byte, short, int, long, float, double, char, boolean. char — UTF-16 код бірлігі; кейбір Unicode таңбасы екі char алады. String пен массивтер сілтемелік типтер. null — сілтеменің жоқтығы. Жергілікті айнымалыны оқудан бұрын инициализациялау қажет. var типті компиляция кезінде шығарады, кейін тип өзгермейді.

## Түрлендіру және амалдар

Үлкен бүтін литералға L қос. int-тен long-қа кеңейту дәл, long-тен double-ға көшу дәлдікті жоғалтуы мүмкін. `(int)-2.9` нәтижесі -2. Integer ішіндегі null мәнін int-ке ашу NullPointerException тудырады. Объект мәндерін equals арқылы салыстыр.

`7 / 2` — 3, `7 / 2.0` — 3.5. Нәтижені кейін double-ға ауыстыру жоғалған бөлшекті қайтармайды. `&&` екінші шартты тек қажет болса есептейді. Биттік операторлар: &, |, ^, ~ және ығыстырулар. `>>` таңбаны сақтайды, `>>>` нөлмен толтырады.

## Дәлдік және шекара

int толып кетуі әдетте ерекшелік бермейді. Math.addExact мұны анықтайды. `long r = a * b` ішінде екі int алдымен int ретінде көбейеді: `(long)a * b` керек. double — жуық мән. Ақша үшін ең кіші ақша бірлігіндегі long немесе жолдан құрылған BigDecimal қолдан. Дөңгелектеу ережесін нақты көрсет.

### 2. Жеңілдік
