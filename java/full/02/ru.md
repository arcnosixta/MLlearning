# Типы, операторы и точные вычисления

Цель: выбирать тип по смыслу данных, предсказывать преобразования и обнаруживать переполнение.

## 1. Примитивы и ссылки

В Java восемь примитивов: byte, short, int, long, float, double, char, boolean. Целые типы знаковые; char — беззнаковая 16-битная единица UTF-16, а не обязательно целый символ Unicode. boolean содержит только true/false. String, массивы и классы — ссылочные типы. Локальные переменные нужно инициализировать до чтения; поля получают начальные значения. `null` обозначает отсутствие ссылки, а не пустую строку или число ноль. `var` выводит статический тип локальной переменной из инициализатора, динамическим язык не становится.

## 2. Литералы и преобразования

Для большого long-литерала используй суффикс L, для float — f. Арифметика byte и short обычно выполняется как int. Расширение int в long сохраняет целое значение; перевод большого long в double может потерять точность. Сужающее приведение требует явного cast и может потерять старшие биты. `(int) -2.9` даёт -2. Автоупаковка превращает int в Integer; распаковка null вызывает NullPointerException. Обёртки сравнивай по значению через equals, а не полагайся на кеширование объектов и `==`.

## 3. Операции и порядок

`7 / 2` даёт 3, `7 / 2.0` — 3.5. Приведение результата `(double)(7 / 2)` уже не восстановит дробную часть. Остаток `%` у отрицательного делимого может быть отрицательным. `&&` и `||` сокращают вычисление, поэтому `x != 0 && 10 / x > 1` безопасно для нуля. `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>` работают с битами; `>>` сохраняет знак, `>>>` заполняет старшие позиции нулями. Скобки делают намерение ясным; избегай нескольких изменений одной переменной в одном выражении.

## 4. Переполнение, Math и деньги

Обычное целочисленное сложение при переполнении не выбрасывает исключение. `Math.addExact` и `multiplyExact` позволяют его обнаружить. Присваивание `long result = a * b` не помогает, если a и b имеют тип int: используй `(long) a * b`. double хранит двоичное приближение: для измерений задавай допустимую погрешность, для денег применяй целые минимальные единицы либо BigDecimal из строки. Деление BigDecimal должно иметь явно выбранное округление. `Math.sqrt` отрицательного числа возвращает NaN; область допустимых входов — часть условия задачи.

## Практика

### 1. Время из секунд

Для неотрицательного числа секунд получи часы, минуты и секунды. Проверь 0, 59, 60, 3661.

{{answer:1}}

<details><summary>Подсказка и решение</summary>

Часы `s / 3600`, минуты `(s % 3600) / 60`, секунды `s % 60`. Для 3661 ответ 1:1:1. Отрицательное значение отклони до вычисления.
</details>

### 2. Стоимость заказа

Цена 19.90, количество 3, скидка 10%. Получи 53.73 с двумя десятичными знаками.

{{answer:2}}

<details><summary>Решение</summary>

Создай BigDecimal из строк, умножь на 3 и 0.90, затем setScale(2, RoundingMode.HALF_UP). Значения цены и количества не должны быть отрицательными.
</details>
