# Тесттеу, Log4j2, TestNG, жинақтау және жоба

Мақсат: келісімі тексерілетін, қайталанып жиналатын қосымша жасау.

## Тест пен диагностика

Тест іске асыруды көшірмейді, сыртқы келісімді тексереді. Arrange, act, assert кезеңдерін бөл. Қалыпты кіріс, шекара және қатені тексер. Unit-тест сыртқы жүйесіз, интеграциялық тест нақты байланыспен жұмыс істейді. Уақытты Clock арқылы бекіт.

TestNG сыртқы кітапхана. @Test және Assert Java assert-тен бөлек, -ea талап етпейді. DataProvider жағдайлар кестесін береді, BeforeMethod/AfterMethod тәуелсіз күй мен cleanup жасайды. Күтілетін ерекшелікті нақты операция маңында тексер. Параллель тесттер ортақ өзгермелі fixture ұстамауы керек.

Log4j API мен Core іске асыруын ажырат. Logger, деңгей, Appender және Layout әртүрлі рөл атқарады. Параметрлі хабарлама мен exception нысанын бер. Пароль, токен және толық жеке деректі логқа жазба. Ротация мен сақтау мерзімін анықта.

Maven pom.xml тәуелділік пен плагинді сипаттайды. src/main/java және src/test/java бөлек. `mvn test`, кейін `mvn package`. Jar барлық тәуелділікті автоматты қамтымайды.

## Қорытынды жоба

Student/Grade моделін, Gradebook сервисін, GradeRepository интерфейсін және файл/JDBC қоймасын бөл. Бірегей ID, 0–100 баға, топ орташасы, экспорт жаса. Қате импорт күйді жартылай өзгертпесін. Қосымша Swing не XML адаптерін бөлек қос.
