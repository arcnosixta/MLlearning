# Кластар, конструкторлар және инкапсуляция

Мақсат: әр ашық операциядан кейін дұрыс күйін сақтайтын нысан құру.

## Күйді қорғау

Класс типті, нысан нақты дананы сипаттайды. Әр нысанның өрістері бөлек, static өріс класқа ортақ. Конструктордың нәтиже типі болмайды. Өз конструкторың болса, параметрсіз нұсқа автоматты қосылмайды. Java 17 ішінде this(...) не super(...) бірінші тұрады. Конструктордан override әдісін шақыру қауіпті: мұрагердің өрістері әлі дайын емес.

Инвариант — нысанның әрдайым сақталатын ережесі. Әмиян балансы теріс болмауы тиіс. Списаниені тексерусіз setter арқылы жасау инкапсуляцияны бұзады. Барлық шартты өзгеріс алдында тексер: қате шақыру күйді жартылай өзгертпеуі керек.

final сілтемені қайта тағайындауға тыйым салады, бірақ массив элементтері өзгеруі мүмкін. Өзгермейтін класс үшін кірісті көшір және ішкі өзгермелі нысанды сыртқа берме. GC файлдарды уақтылы жабуды қамтамасыз етпейді.
