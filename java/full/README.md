# Java: полный курс по материалам / Толық курс

Самостоятельный маршрут из 26 подробных глав: от установки JDK до многопоточности,
JDBC, сетей, XML, GUI и проекта. Базовый семестр из 14 недель остаётся маршрутом
подготовки к РК; полные главы расширяют его и углублённый курс.

26 тараудан тұратын жеке бағыт: JDK орнатудан көпағындылыққа, JDBC, желі, XML,
графикалық интерфейс пен жобаға дейін. Бұрынғы 14 апталық семестр РК бағыты ретінде сақталады.

## Как учиться

1. Прочитай цель и теорию главы. Выпиши непонятные термины.
2. Предскажи вывод полного примера, затем запусти его с JDK 17+.
3. Измени один параметр и объясни изменение результата.
4. Реши три задания: базовое, прикладное и на границы. Подсказку открывай после своей попытки.
5. Ответь на вопросы самопроверки и сохрани собственное решение на сайте.

У каждой главы есть русский и казахский текст, исходник `Main.java`, ожидаемый
вывод, задачи с подсказками и решениями. Код совместим с `javac --release 17`.
Внешние системы нужны только для явно обозначенных дополнительных лабораторных.

## Версии и исторические API

База курса — Java 17 без preview. `record`, switch expressions и HttpClient
доступны в этой версии. Date/Calendar, Vector/Stack, Observable, applet, finalize,
Thread.stop/suspend/resume разбираются как исторические конструкции с объяснением
ограничений и современных альтернатив. Java EE API, JDBC-драйверы, JavaMail,
Log4j2 и TestNG не являются частью JDK: дополнительные работы явно указывают зависимости.
Base64 — кодирование, а не шифрование; хеширование также не заменяет шифрование.
