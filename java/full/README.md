# Java: полный курс по материалам / Толық курс

Сайт: маршрут `#java/full`, отдельная глава: `#java/topic/01` … `#java/topic/26`.
Ссылка «Полный курс · 26 глав» находится в карточках базового и углублённого Java.

Каталог поддерживает поиск и фильтр завершённых/непройденных глав; параметры
сохраняются в ссылке при навигации и смене языка. Следующий шаг выбирается среди
видимых непройденных глав. Отметка главы обратима и не удаляет написанное решение.

Весь курс можно скачать как `java-full/study.zip`: 26 независимых Main.java,
ожидаемые результаты, RU/ҚАЗ разборы и дополнительная Maven-лабораторная. README
в архиве содержит команды запуска, MANIFEST.sha256 — контрольные суммы.

Главная и каталог получают небольшой index.json, текст главы — при её открытии.
При ошибке загрузки доступна повторная попытка, сохранённые ответы не удаляются.

Самостоятельный маршрут из 26 подробных глав: от установки JDK до многопоточности,
JDBC, сетей, XML, GUI и проекта. Базовый семестр из 14 недель остаётся маршрутом
подготовки к РК; полные главы расширяют его и углублённый курс.

26 тараудан тұратын жеке бағыт: JDK орнатудан көпағындылыққа, JDBC, желі, XML,
графикалық интерфейс пен жобаға дейін. Бұрынғы 14 апталық семестр РК бағыты ретінде сақталады.

## Как учиться

1. Прочитай цель и теорию главы. Выпиши непонятные термины.
2. Предскажи вывод полного примера, затем запусти его с JDK 17+.
3. Измени один параметр и объясни изменение результата.
4. Реши три задания: базовое, прикладное и на границы. Подсказку открывай после своей попытки.
5. Ответь на вопросы самопроверки и сохрани собственное решение на сайте.

У каждой главы есть русский и казахский текст, исходник `Main.java`, ожидаемый
вывод, задачи с подсказками и решениями. Код совместим с `javac --release 17`.
Внешние системы нужны только для явно обозначенных дополнительных лабораторных.

## Версии и исторические API

База курса — Java 17 без preview. `record`, switch expressions и HttpClient
доступны в этой версии. Date/Calendar, Vector/Stack, Observable, applet, finalize,
Thread.stop/suspend/resume разбираются как исторические конструкции с объяснением
ограничений и современных альтернатив. Java EE API, JDBC-драйверы, JavaMail,
Log4j2 и TestNG не являются частью JDK: дополнительные работы явно указывают зависимости.
Base64 — кодирование, а не шифрование; хеширование также не заменяет шифрование.

## Сборка и проверка

```sh
python scripts/build.py
python tests/verify_java_full.py
python tests/verify_java.py
# Драйвер H2 2.3.232 скачивается отдельно из Maven Central:
python tests/verify_java_jdbc.py /path/to/h2-2.3.232.jar
python -m zipfile -e dist/java-full/25/lab.zip artifacts/java-maven-lab
mvn -B -f artifacts/java-maven-lab/pom.xml test
```

При запущенном сервере `dist/` на порту 8765: `python tests/browser_java_full.py`.
Для установленного Edge в Windows задай `$env:PLAYWRIGHT_CHANNEL='msedge'`;
в CI используется Playwright Chromium. Нужны Python-зависимости основного
репозитория, Playwright и JDK. Для Maven-лабораторной нужен отдельный Maven.
Дополнительные инструменты извлечения PDF/PPT не нужны для сборки сайта.

## Поддержка курса

`catalog.json` содержит порядок, связи с семестром и ссылки на источники.
В каталоге каждой главы лежат `ru.md`, `kk.md`, `Main.java`, `output.txt`.
Метка `{{example}}` в обоих текстах заменяется одним и тем же проверенным кодом
и ожидаемым выводом. Метки `{{answer:1}}` … `{{answer:3}}` становятся полями
для самостоятельного решения. Три блока details содержат подсказки и разборы.
Markdown проходит HTML-очистку при сборке, пользовательский ответ выводится
через значение textarea. Java-код в браузере не исполняется.

Для практики TestNG/Log4j2 исходники `25/lab/` упаковываются вместе с актуальным
`25/Main.java` в `dist/java-full/25/lab.zip`; временные метки и порядок записей
архива фиксированы. В репозиторий не включаются Maven target, драйверы и JDK.
Ответы хранятся как `learning.practice['java-full/01/1']`, завершение — как
`learning.completed` со значениями `java-full/01`. Старые резервные копии
версии 1 по-прежнему принимаются.

Проверки покрытия, компиляции, JDBC, Maven и браузера добавлены в GitHub Actions.
Подробная [сводка локальной проверки](VALIDATION.md) указывает её границы.
