# Ерекшеліктер, қателер және ресурстар

Мақсат: қате себебін жоғалтпай, операцияны дұрыс аяқтау.

## Қате келісімі

Throwable тармақтары — Error және Exception. RuntimeException тексерілмейді; басқа Exception түрлері әдетте catch не throws талап етеді. throw басқаруды ерекшелікпен береді, throws мүмкін қатені жариялайды. Error-ды ұстап жұмысты жалғастыру әрдайым мүмкін емес.

catch нақты типтен жалпы типке қарай орналасады. Қалпына келтіру не түсінікті жауап беру мүмкін жерде ғана ұста. Бос catch қатені жасырады. Жаңа ерекшелікке бастапқы cause-ты бер. finally ішіндегі return бастапқы нәтижені жасыра алады.

try-with-resources AutoCloseable ресурстарын кері ретпен жабады. Дене қатесі негізгі, close қатесі suppressed болады. GC файлды уақытында жабуға кепіл емес. assert әдетте өшірулі; `-ea` қосады. Пайдаланушы енгізуін assert арқылы тексерме.
