# Коллекции: List, Set, Map, Queue и Deque

Цель: выбирать структуру по операциям и соблюдать контракт порядка и равенства.

## Список и сложность

List сохраняет последовательность и допускает повторы. ArrayList хранит массив: доступ по индексу O(1), добавление в конец амортизированно O(1), вставка в середину сдвигает хвост. LinkedList хранит узлы: поиск позиции O(n), поэтому цикл get(i) по всему списку может стать O(n²). Удаление через уже полученный итератор не требует повторного поиска. Обычно ArrayList — разумная начальная реализация. List.of неизменяем и не принимает null; Arrays.asList даёт список фиксированного размера, связанный с исходным массивом.

## Множества и карты

Set хранит уникальные элементы. HashSet/HashMap используют hashCode и equals, не обещают порядок обхода. LinkedHashSet/LinkedHashMap сохраняют порядок вставки. TreeSet/TreeMap сортируют по естественному порядку или Comparator, операции поиска обычно O(log n). Для дерева compare(a,b)==0 означает один ключ даже при другом equals, поэтому согласуй порядок с равенством. Не изменяй значимые поля ключа после вставки. Map не является Collection: она отображает ключ на значение, а views keySet/values/entrySet связаны с исходной картой.

## Итераторы и изменение

Структурное изменение обычной коллекции внутри for-each может вызвать ConcurrentModificationException даже в одном потоке. Используй iterator.remove либо removeIf. Fail-fast — помощь в обнаружении ошибки, а не гарантия потокобезопасности. Изменение значения существующей записи и изменение структуры различаются по контракту реализации. Unmodifiable-view запрещает операции через представление, но может отражать изменения исходника; copyOf отделяет структуру копии, не копируя глубоко элементы.

## Очереди и алгоритмы

Queue моделирует выдачу работы, Deque поддерживает оба конца. Для стека применяй ArrayDeque с push/pop вместо устаревшего Stack, для FIFO — offer/poll. poll возвращает null при пустоте, remove выбрасывает исключение. ArrayDeque запрещает null. PriorityQueue выдаёт минимальный элемент по порядку, но её итератор не является отсортированным обходом. Для enum существуют EnumSet и EnumMap. Legacy Vector/Hashtable синхронизируют методы, однако последовательность «проверил, затем изменил» не становится атомарной автоматически.
