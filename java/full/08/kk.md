# Интерфейстер, композиция, enum және record

Мақсат: келісімді іске асырудан бөліп, күйлерді типпен шектеу.

## Келісім мен дерек

Класс бірнеше интерфейсті іске асыра алады. Интерфейс өрістері public static final; олар экземпляр күйі емес. Abstract әдісі public болғандықтан іске асыру да public болуы керек. Екі default әдіс қайшы келсе, класс таңдауды өзі анықтайды.

Композицияда сервиске дайын Formatter беріледі. Сервис нақты класқа байланбайды, тестте басқа іске асыруды қолдануға болады. null тәуелділікті конструкторда қабылдама.

enum шекті күйлер жиынын береді. Константаларды == арқылы салыстыруға болады. ordinal жариялау ретін көрсетеді, оны тұрақты сыртқы ID ретінде сақтама. name және valueOf программалық атаумен жұмыс істейді.

record аксессорлар, equals, hashCode және toString жасайды. final өріс терең өзгермейтіндікті білдірмейді: List компонентін компакт конструкторда List.copyOf арқылы көшір. Record мәндер үшін ыңғайлы; өзгермелі өмірлік циклі бар сущность үшін әрдайым сәйкес емес.
