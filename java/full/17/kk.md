# Файлдар, енгізу/шығару, NIO және сериализация

Мақсат: мәтін мен байтты ажыратып, ресурстарды уақытында жабу.

## Ағын мен файл

InputStream/OutputStream байтпен, Reader/Writer символмен жұмыс істейді. Кодировканы нақты көрсет. read -1 қайтарса ағын бітті; 0 — заңды дерек. Буфердің тек оқылған бөлігін өңде. DataInputStream мен DataOutputStream өрістерді бірдей ретпен оқуы және жазуы тиіс.

Path жолды сипаттайды, Files операция жасайды. Салыстырмалы жол жұмыс каталогынан есептеледі. Үлкен файлды ағынмен оқы. Files.lines/list/walk нәтижесін жап. exists кейін файл өзгеруі мүмкін: нақты операция қатесін өңде.

ByteBuffer ішінде position, limit, capacity бар. flip жазылған бөлікті оқуға дайындайды; clear жаңа жазуға дайындайды, деректі физикалық өшірмейді. Channel толық көлемді бір шақыруда беруге міндетті емес.

Serializable нысан күйін сақтайды; transient және static стандартты экземпляр күйіне кірмейді. serialVersionUID семантикалық миграцияны шешпейді. Сенімсіз ObjectInputStream не XMLDecoder кірісін қабылдама. ZIP атаулары каталогтан шықпауы тиіс. Scanner nextInt кейін nextLine бос қалдықты оқуы мүмкін. Жазуды уақытша файл және соңғы көшіру арқылы ұйымдастыр; ATOMIC_MOVE қолдауын тексер.
