# Массивтер, матрицалар, іздеу және сұрыптау

Мақсат: индекстерді дұрыс қолданып, алгоритмнің шарттары мен күрделілігін түсіндіру.

## Массив келісімі

Массив — ұзындығы тұрақты нысан. Индекстер 0-ден length-1-ге дейін. b=a сілтемені көшіреді; Arrays.copyOf жаңа массив жасайды, бірақ нысандардың өздерін көшірмейді. Екіөлшемді массив жолдардан тұрады: олардың ұзындығы әртүрлі немесе мәні null болуы мүмкін.

for-each элементті оқуға ыңғайлы; цикл айнымалысына жаңа мән беру массив элементін алмастырмайды. Максимумды бірінші элементтен баста, нөлден емес. Бос массивтің нәтижесін келісімде анықта. Үлкен қосындыға long қолдан.

Сызықтық іздеу O(n). Бинарлық іздеу O(log n), бірақ сұрыпталған массивті талап етеді. [left,right) аралығында төменгі шекараны іздеу қайталанатын мәннің алғашқы орнын табады. mid мәнін `left+(right-left)/2` арқылы есепте.

Таңдау және кірістіру сұрыптауларының жалпы қиындығы O(n²). Тәжірибеде Arrays.sort қолдан. Екі сұрыпталған массивті біріктіру O(n+m). Транспонирлеуде n×m өлшемі m×n болады.

## Практика

### 1. Кері айналдыру

Массивті қосымша массивсіз айналдыр. Бос және жалғыз элементті тексер.

{{answer:1}}

<details><summary>Шешім</summary>

Сол және оң элементтерді алмастырып, индекстерді ортасына жылжыт. left < right кезінде ғана айырбаста. Жад O(1).
</details>

### 2. Біріктіру

[1,3,3] және [2,3,5] массивтерін біріктір.

{{answer:2}}

<details><summary>Шешім</summary>

Екі көрсеткішпен кішісін көшір, соңында қалған бөлікті қос. Нәтиже [1,2,3,3,3,5], қайталанулар сақталады.
</details>

### 3. Жол қосындылары

Әртүрлі ұзындықтағы int[][] жолдарының қосындысын тап. null жол — бос жол.

{{answer:3}}

<details><summary>Шешім және тексеру</summary>

long[] жаса, null жолды өткізіп, әр жолдың өз ұзындығын қолдан. Неліктен clone матрица элементтерін терең көшірмейді? Бинарлық іздеу қандай шартты талап етеді?
</details>
