# Массивы, матрицы, поиск и сортировка

Цель: управлять индексами, выбирать алгоритм и проверять результат на граничных данных.

## Устройство массива

Массив — объект фиксированной длины с элементами одного типа. Индексы идут от 0 до length-1; доступ за пределами вызывает исключение. `new int[3]` заполнен нулями, массив ссылок — null. Присваивание b=a копирует ссылку: изменения видны через обе переменные. `Arrays.copyOf` создаёт новый массив; для массива объектов копируются ссылки, а не сами объекты. Двумерный массив — массив строк-массивов: строки могут иметь разную длину или быть null.

## Обход и преобразование

Для чтения используй for-each. Присваивание переменной цикла не заменяет элемент массива: для изменения нужен индекс. Максимум непустого массива инициализируй первым элементом, а не нулём — иначе все отрицательные числа дадут ошибку. Пустой массив требует отдельного контракта: исключение, OptionalInt или специально оговорённое значение. Для суммы int-элементов выбирай long, если диапазон может переполниться.

## Поиск и сложность

Линейный поиск проверяет до n элементов и работает без сортировки. Бинарный поиск требует отсортированных данных и уменьшает диапазон вдвое: O(log n). Удобен полуинтервал [left,right): при поиске нижней границы ответ равен первому индексу со значением не меньше ключа. `mid = left + (right-left)/2` избегает переполнения суммы индексов. При дубликатах обычный binarySearch не обещает первый индекс.

## Сортировки и матрицы

Выбором: найди минимум хвоста и обменяй с текущим элементом, O(n²), обычно нестабильно. Вставками: вставляй очередное значение в отсортированный префикс; на почти отсортированных данных удобно. Для реального кода начни с Arrays.sort. Слияние двух отсортированных массивов проходит их указателями за O(n+m). Для транспонирования прямоугольной матрицы n×m выдели m×n; главная диагональ существует до min(n,m). Не путай число строк с длиной конкретной строки.
