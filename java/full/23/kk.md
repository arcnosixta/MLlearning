# Жобалау үлгілері және архитектура таңдау

Мақсат: қайталанатын мәселені танып, үлгінің пайдасы мен құнын түсіндіру.

## Негізгі үлгілер

Factory Method өнім жасауды override әдісіне береді; жай static фабрика онымен бірдей емес. Abstract Factory өнімдер тобын, Builder кезеңдік құруды, Prototype көшіруді ұйымдастырады. Singleton жалғыз экземплярды шектейді, бірақ тест пен тәуелділікті қиындатуы мүмкін.

Composite жапырақ пен топты бір келісіммен өңдейді, циклге жол бермеу керек. Adapter бөгде интерфейсті қажет интерфейске аударады. Proxy қолжетімділікті бақылайды; Decorator әрекет қосады; Facade күрделі жүйеге қарапайым кіру береді. Bridge екі өзгеру осін бөледі, Flyweight ортақ өзгермейтін күйді бөліседі.

Observer тыңдаушыларды хабардар етеді: жазылу, шығу және қате саясаты қажет. Strategy алгоритмді алмастырады, State күй мен өтулерді байланыстырады. Template Method алгоритм қаңқасын сақтайды. Command сұрауды нысан етеді; Chain өңдеушілер тізбегін, Iterator өтуді, Mediator байланысты, Memento қалпына келуді, Interpreter грамматиканы, Visitor жаңа операцияны ұйымдастырады. Үлгіні нақты өзгермелілік үшін таңда.
