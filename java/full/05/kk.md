# Әдістер, рекурсия, пакеттер және құжаттама

Мақсат: есепті келісімі анық, бөлек тексерілетін әрекеттерге бөлу.

## Әдіс келісімі

Алдымен кіріс шартын, нәтижені және жанама әсерді жаз. Есептеу әдісін консоль оқуынан бөл. Сигнатураны атау мен параметр типтері анықтайды; тек нәтиже типімен overload жасауға болмайды. Java мәнді береді: нысанға сілтеме де көшіріледі. Параметр арқылы нысанды өзгертуге болады, бірақ параметрді қайта тағайындау сыртқы айнымалыны өзгертпейді.

Varargs соңғы параметр болуы керек және ішінде массив болып көрінеді. Рекурсияда базалық жағдай мен соған жақындайтын қадам қажет. Әр шақыру стек орнын алады. Fibonacci-ді тікелей рекурсиямен есептеу қайталанатын жұмысты көбейтеді.

Пакет атаулар қақтығысын азайтады. `package study.math;` үшін файлды сәйкес қалтаға қойып, `javac -d out ...` және `java -cp out study.math.Main` орында. import сыртқы кітапхананы жүктемейді. Javadoc ішіндегі @param, @return, @throws келісімді түсіндіреді.

## Практика

### 1. Орташа

[2,3] үшін 2.5 қайтар, бос массивті қабылдама.

{{answer:1}}

<details><summary>Шешім</summary>

null мен ұзындықты тексер. Қосындыға long, бөлу алдында double түрлендіруін қолдан.
</details>

### 2. Сілтеме

`a[0]=9; a=new int[]{7};` әдісінен кейін [1,2] неге тең?

{{answer:2}}

<details><summary>Шешім</summary>

[9,2]. Элемент ортақ нысанда өзгерді, ал жаңа массив тек жергілікті параметрге тағайындалды.
</details>

### 3. Дәреже

Теріс емес көрсеткіш үшін дәрежені екіге бөлу әдісімен есепте.

</details>
