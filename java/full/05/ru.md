# Методы, рекурсия, пакеты и документация

Цель: делить задачу на небольшие проверяемые операции с ясным контрактом.

## Контракт метода

Сигнатура включает имя и типы параметров; возвращаемый тип сам по себе не различает перегрузки. Опиши допустимые входы, результат и побочные эффекты до написания тела. Метод вычисления среднего не должен одновременно читать клавиатуру и сохранять файл: разделение позволяет проверить его без консоли. return завершает метод, void означает отсутствие возвращаемого значения. Доступность выбирай минимальную; public — обещание пользователям класса.

## Передача параметров и перегрузка

Java всегда передаёт значения. Для объекта копируется значение ссылки: метод может изменить объект, но присваивание параметру нового объекта не заменит переменную вызывающего кода. Перегрузка выбирается при компиляции по объявленным типам. Варианты с несколькими несвязанными ссылочными типами делают вызов с null неоднозначным. Varargs `int... values` внутри метода является массивом и должен быть последним параметром. Не создавай перегрузки, отличающиеся только неочевидной упаковкой.

## Рекурсия

Рекурсивный метод имеет базовый случай и шаг, приближающий к нему. Каждый вызов занимает кадр стека; глубина ограничена. Для факториала проверь n >= 0; базовый случай 0! = 1. Наивный рекурсивный Fibonacci многократно пересчитывает подзадачи, поэтому итерация или мемоизация эффективнее. При обходе дерева рекурсия естественна, но глубоко вложенные входы лучше обрабатывать явным стеком.

## Пакеты, импорт и Javadoc

Пакет задаёт пространство имён и границу доступа. `package study.math;` соответствует расположению исходника study/math/Main.java. Из корня запускай `javac -d out study/math/Main.java`, затем `java -cp out study.math.Main`. import сокращает запись имени и не загружает библиотеку из интернета. Статический импорт удобен для отдельных функций, но избыток скрывает происхождение методов. Javadoc-комментарий `/** ... */` документирует API: @param, @return, @throws. Пиши условия и гарантии, а не пересказ имени.
