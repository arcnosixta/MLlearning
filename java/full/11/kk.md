# Күн, уақыт, пішімдеу және локализация

Мақсат: күнтізбелік күнді нақты уақыт сәтінен, сақтауды көрсетуден ажырату.

## Уақыт түрлері

LocalDate — күн, LocalTime — тәулік уақыты. LocalDateTime ішінде уақыт белдеуі жоқ. Instant нақты сәтті, ZonedDateTime белдеу ережесімен жергілікті уақытты көрсетеді. OffsetDateTime тек ығысуды ұстайды. Date/Calendar ескі API шекарасында кездеседі; жаңа кодта java.time қолдан.

Period күнтізбелік бөліктерді, Duration секундтарды сипаттайды. Бір күн кейбір белдеулерде 24 сағатқа тең болмауы мүмкін. plusDays бастапқы нысанды өзгертпейді. DateTimeFormatter өзгермейді. Қатаң тексеруге uuuu-MM-dd және STRICT қолдан.

Тестке Clock.fixed бер: нәтиже бүгінгі күнге тәуелсіз болады. Locale тілдік пішімді, ZoneId уақыт белдеуін анықтайды. ResourceBundle мәтінді кілт арқылы тілден бөледі; базалық файл fallback үшін қажет. Машиналық алмасуға ISO пішімін, пайдаланушыға локаль пішімін таңда.
