# Ветвления, циклы и численные алгоритмы

Цель: переводить условие задачи в алгоритм с понятными границами и доказуемым завершением.

## Условия и switch

if принимает boolean. Для интервала `a <= x && x <= b` нужны два сравнения: цепочка `a <= x <= b` недопустима. В цепочке if/else if выполняется первая подходящая ветка, поэтому более узкие условия ставь раньше общих. Блоки со скобками предотвращают ошибочное присоединение else. switch statement с двоеточиями может проваливаться в следующую ветку без break; switch expression со стрелками возвращает значение, а блок возвращает его через yield. Для обычных ссылочных селекторов в Java 17 заранее исключай null.

## Выбор цикла

for удобен для известного числа шагов, while — для повторения до события, do/while выполняет тело хотя бы раз. В for инициализация выполняется однажды, затем проверка, тело и шаг. break завершает ближайший цикл; continue переходит к следующей итерации. Во вложенных циклах оцени общее число повторов: n на m даёт O(nm). Не изменяй счётчик скрыто в нескольких местах.

## Инвариант и завершение

Инвариант — утверждение, истинное перед каждой итерацией. В суммировании первых k чисел аккумулятор содержит сумму уже обработанных элементов. Инициализируй его нулём, произведение — единицей. Завершение доказывай убыванием неотрицательного остатка работы. Для алгоритма Евклида остаток от деления меньше делителя, поэтому процесс дойдёт до нуля. Проверяй пустой диапазон и первое/последнее значение.

## Приближённые вычисления

Для суммы ряда введи точность eps и максимум итераций: одно сравнение с eps не защищает от расходимости и NaN. При табулировании функции вычисляй `x = start + i * step`, а не накапливай ошибку многократным сложением шага. Явно проверяй область определения, нулевой шаг и направление диапазона. Для факториала long переполняется начиная с 21!, поэтому границу нужно ограничить или перейти к BigInteger.
