# Тармақталу, циклдер және сандық алгоритмдер

Мақсат: шартты аяқталатын, шекаралары тексерілетін алгоритмге айналдыру.

## Негізгі ережелер

if логикалық өрнек алады. Аралық `a <= x && x <= b` түрінде жазылады. if/else if бірінші сәйкес тармақты орындайды. switch ішіндегі қос нүктелі нұсқа break болмаса келесі тармаққа өтеді; Java 17 switch expression ішінде нәтиже стрелкамен немесе yield арқылы беріледі.

for белгілі қадам санына, while оқиғаға дейін қайталауға қолайлы. do/while кемінде бір рет орындалады. break циклді тоқтатады, continue келесі итерацияға өтеді. Қос циклдің жұмысы O(nm) болуы мүмкін.

Инвариант әр итерация алдында сақталады: аккумулятор өңделген элементтердің қосындысын ұстайды. Аяқталуды қалған жұмыстың кемуімен түсіндір. Евклид алгоритмінде қалдық бөлгіштен кіші. Жуық қатарға eps және қадам шегін бірге енгіз; NaN мен шексіздікті тексер. Табуляцияда x мәнін start + i*step арқылы есепте.

### 2. Цифрлар қосындысы

{{answer:2}}

<details><summary>Шешім</summary>
