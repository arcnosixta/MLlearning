# Проверка полного курса Java

Дата локальной проверки: 26 октября 2026 года.

## Содержание

- 26 глав с русским и казахским текстом, 26 независимых примеров и 78 задач.
- Все 15 глав Java from EPAM и темы приложений Log4j2/TestNG сопоставлены
  с маршрутами курса; презентации добавляют алгоритмы, паттерны и GUI,
  сборник задач — численные алгоритмы, динамические структуры и автоматы.
- Источники учтены по именам и SHA-256, оригинальные PDF/PPT и извлечённый
  текст остаются вне Git и опубликованной сборки.

Локальная компиляция и выполнение сделаны установленным JDK 25 с ограничением
компиляции Java 17; GitHub Actions запускает те же проверки на настоящем JDK 17.
Браузерная проверка выполнена Playwright с установленным Microsoft Edge.
Драйвер, Maven и Node загружены в игнорируемый artifacts; целостность загрузок
сверена с контрольными суммами поставщиков. Основная сборка их не требует.

## Границы проверки

Проверяются все полные примеры, но не каждая возможная самостоятельная программа
студента из текстовых заданий. Поля ответов сохраняют рассуждение, автоматической
проверки произвольного Java-кода на сайте нет.

Для Swing проверено рисование BufferedImage без экрана; отдельное окно
`java Main --window` требует ручной проверки в графической сессии. Реальный
Servlet-контейнер, SMTP-сервер, внешние HTTP-сервисы и все возможные СУБД
не поднимались. Их контракты и необходимые зависимости описаны как дальнейшие
лабораторные; JDBC проверен именно на H2. Результаты существующих тестов 1С
проверяют структуру исходников, а не выполнение в проприетарной платформе.

Git push и публикация сайта — разные операции. Отправка исходников в GitHub
сама по себе не доказывает обновление отдельного хостинга Sites.
