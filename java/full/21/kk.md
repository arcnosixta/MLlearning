# Желілер: TCP, UDP, HTTP және сервер

Мақсат: тасымал, хабарлама шекарасы және қолданбалы протоколды ажырату.

## Желілік келісім

IP мекенжайды, порт қолданба нүктесін, DNS атау мен мекенжай байланысын береді. TCP реттелген байт ағыны, хабарлама шекарасы жоқ. UDP датаграммалары жоғалуы не қайталануы мүмкін. VPN өздігінен әр қолданбаны сенімді етпейді.

ServerSocket accept арқылы Socket береді. Протоколға жол соңы не ұзындық префиксін таңда. Бір read бір хабарламаға тең емес. Екі жақ та алдымен оқуды күтсе, тоқтап қалуы мүмкін. Таймаут, UTF-8 және flush келісімін анықта; клиент санын шекте.

HTTP әдіс, жол, заголовок және денеден тұрады. 2xx сәтті, 4xx сұрау қатесі, 5xx сервер қатесі. HTTPS TLS қолданады; сертификат тексеруін өшірме. HttpClient Java 17 ішінде бар, бірақ 404-ті statusCode арқылы өзің тексересің. Қайталау идемпотенттік пен жалпы мерзімді ескеруі тиіс. Servlet API және Mail кітапханалары сыртқы тәуелділіктер; Servlet үшін контейнер керек. REST стиль, SOAP XML хабарламалар протоколы, RPC қашық операция моделін береді.
