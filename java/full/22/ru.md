# XML: DOM, SAX, StAX, XPath и XSD

Цель: выбирать модель обработки XML, валидировать структуру и не разрешать непредусмотренные внешние ресурсы.

## Документ и схема

XML содержит элементы, атрибуты и текст; теги должны правильно вкладываться, документ имеет один корень. Well-formed означает синтаксическую корректность, valid — соответствие схеме. Namespace задаёт URI пространства имён; префикс является локальным сокращением и может изменяться. Для сравнения имён используй namespace URI и local name, а не строку префикса. XSD задаёт типы, обязательность, порядок, количество элементов и ограничения значений. DTD — другой, более старый механизм описания структуры.

## DOM и XPath

DOM загружает дерево целиком: удобно искать, менять и создавать элементы, но память растёт с документом. DocumentBuilderFactory создаёт настроенный builder. getElementsByTagName ищет потомков, а не только прямых детей: это важно для вложенных одноимённых узлов. Текст может включать форматирующие пробелы. XPath выбирает узлы и вычисляет выражения; для namespace-aware документа установи NamespaceContext. Для записи Document используй Transformer и задавай кодировку, не собирай XML конкатенацией неэкранированного текста.

## SAX и StAX

SAX — push-модель: парсер вызывает startElement, characters, endElement обработчика. Один текстовый узел может прийти несколькими вызовами characters; накапливай текст до endElement. StAX — pull-модель: программа сама запрашивает следующее событие. Обе модели позволяют не держать весь документ в памяти, но требуют явного состояния обработки. Закрывай XMLStreamReader и исходный поток по их собственным контрактам. Нельзя ожидать, что XML-парсер вернёт весь текст элемента одним событием.

## Валидация и внешние сущности

SchemaFactory создаёт XSD Schema, Validator проверяет вход. Запрети непредусмотренный доступ к внешним DTD и схемам через XMLConstants.ACCESS_EXTERNAL_DTD/SCHEMA. Для DOM/SAX также настрой безопасную обработку и политику DOCTYPE; один setExpandEntityReferences(false) не заменяет все ограничения. Нужные внешние ресурсы разрешай через контролируемый resolver, а не общий интернет. Ограничивай размер входа. JAXB в Java 17 не входит в стандартный JDK, в отличие от базового JAXP java.xml; XMLEncoder не заменяет универсальное связывание XML с моделью.

### 2. SAX-текст

{{answer:2}}

<details><summary>Разбор</summary>

Начни новый StringBuilder в startElement, добавляй char[] с offset/length при каждом characters, используй итог на endElement. Для вложенных элементов определи стек состояния.
