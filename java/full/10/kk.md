# Жолдар, Unicode, regex және кодтау

Мақсат: мәтіндегі сілтеме, код бірлігі және байт ұғымдарын ажырату.

## Мәтін ережелері

String өзгермейді: replace нәтижесін сақтау керек. equals мазмұнды салыстырады. length UTF-16 бірліктерін санайды; кейбір таңбалар екі бірлік алады. codePoints код нүктелерін береді, бірақ көрінетін графема бірнеше нүктеден тұруы мүмкін. Көп рет біріктіруге StringBuilder қолдан. StringBuffer жеке операцияларды синхрондайды, бүкіл алгоритмді автоматты атомарлы етпейді.

Pattern өрнекті компиляциялайды, Matcher іздеу күйін ұстайды. matches толық мәтінді, find фрагментті тексереді. Java жолында regex слешін қосымша экрандау қажет. Пайдаланушы енгізген тура мәтінге Pattern.quote, ауыстыру мәтініне quoteReplacement қолдан.

UTF-8 кодировкасын екі бағытта да нақты көрсет. Base64 байттарды мәтінге кодтайды, құпияламайды. SHA-256 — хеш, шифрлау емес. Пароль үшін жылдам жай хеш жеткіліксіз. Локальға тәуелсіз техникалық регистрге Locale.ROOT таңда.
