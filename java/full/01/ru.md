# Платформа Java и первая программа

Цель: самостоятельно пройти путь от файла исходного кода до работающей программы и объяснить роль каждого инструмента.

## 1. JDK, JVM и переносимость

Java — язык и платформа. JDK содержит компилятор `javac`, команду запуска `java`, архиватор `jar`, генератор документации `javadoc` и библиотеки. JVM выполняет байткод и управляет памятью. JRE означает среду выполнения; для курса устанавливай именно JDK. Компиляция превращает `Main.java` в `Main.class`. JVM для конкретной ОС загружает класс, проверяет байткод и выполняет его; горячие участки могут компилироваться JIT в машинный код. Переносимость не отменяет различий путей, кодировок и внешних библиотек.

## 2. Установка и диагностика

Проверь `java -version` и `javac -version`. Если первая команда найдена, а вторая нет, проверь установленный JDK и PATH. Создай отдельную папку без других классов Main. Сохрани пример в UTF-8. Выполни `javac --release 17 -encoding UTF-8 Main.java`, затем `java Main`. В команде запуска нет `.class`. `--release 17` ограничивает язык и доступные стандартные API версией 17, даже если установлен более новый JDK. IDE автоматизирует эти команды, но не заменяет понимание процесса.

## 3. Как читать main

`public class Main` объявляет класс, имя файла совпадает с именем публичного класса. `public static void main(String[] args)` — точка входа: метод доступен среде запуска, вызывается без создания объекта, не возвращает значение и получает аргументы командной строки. Скобки задают блок, точка с запятой завершает инструкцию. `System.out.println` печатает значение и перевод строки. Имена чувствительны к регистру: Main и main различаются.

## 4. Первые модели программирования

Процедурный подход описывает последовательность действий. ООП объединяет состояние и операции в объектах: у счётчика есть значение и операция увеличения. Функциональный подход выделяет преобразования данных: функция удвоения возвращает результат без изменения внешнего состояния. Эти подходы совместимы. Пока важно различать значение, переменную, выражение, метод и объект. Комментарий объясняет причину решения; Javadoc описывает публичный контракт. Компилятор не проверяет правильность комментария.
