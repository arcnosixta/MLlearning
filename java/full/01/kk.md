# Java платформасы және алғашқы бағдарлама

Мақсат: бастапқы файлды компиляциялап, бағдарламаны орындау және әр құралдың қызметін түсіндіру.

## Платформа қалай жұмыс істейді

JDK ішінде `javac`, `java`, `jar`, `javadoc` және стандартты кітапханалар бар. JVM байткодты орындайды, жадты басқарады. JRE — орындау ортасы; код жазу үшін JDK керек. `Main.java` компиляциядан кейін `Main.class` болады. Әр операциялық жүйенің JVM іске асыруы бар; файл жолдары мен кодировкалар бәрібір ерекшеленуі мүмкін.

## Алғашқы іске қосу

`java -version` және `javac -version` пәрмендерін тексер. Файлды жеке қалтада UTF-8 түрінде сақта. `javac --release 17 -encoding UTF-8 Main.java`, кейін `java Main` орында. Соңғы пәрменге `.class` қосылмайды. Публичті класс атауы файл атауымен сәйкес болуы керек. Java әріп регистрін ажыратады.

## main және бағдарламалау тәсілдері

`public static void main(String[] args)` — кіру нүктесі. `static` әдісті нысансыз шақыруға мүмкіндік береді, `void` нәтиже қайтармайды, args пәрмен жолының аргументтерін ұстайды. `println` жаңа жолмен шығарады. ООП күй мен әрекетті нысанға біріктіреді; функционалдық тәсіл деректерді түрлендіретін функцияларға сүйенеді. Екеуі бір бағдарламада қолданылады.
