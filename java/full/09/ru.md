# Object, вложенные классы, аннотации и reflection

Цель: понимать равенство объектов, скрытые связи вложенных классов и пределы динамического анализа типов.

## Object и контракт равенства

Любой обычный класс прямо или косвенно наследует Object. `==` проверяет идентичность ссылок; equals задаёт логическое равенство. Оно должно быть рефлексивным, симметричным, транзитивным, согласованным и давать false для null. Если equals истинно, hashCode обязан совпадать; обратное неверно. Используй одни и те же значимые поля. Изменение этих полей у ключа HashMap после вставки может сделать запись недоступной обычным поиском. toString предназначен для понятной диагностики, не для устойчивого формата хранения.

## Копирование и время жизни

Object.clone создаёт поверхностную копию, требует соответствующего контракта Cloneable и плохо выражает инварианты. Копирующий конструктор или фабрика часто яснее. Глубокая копия должна учитывать общие ссылки и циклы. GC собирает недостижимые объекты, а не обязательно сразу после выхода из блока. System.gc — запрос, а не обещание. На finalize нельзя строить освобождение ресурсов; используй AutoCloseable и try-with-resources. native обозначает реализацию вне Java, требует отдельного нативного кода и нарушает простую переносимость примера.

## Вложенные классы

Статический nested-класс не удерживает внешнюю экземплярную ссылку. Inner-класс связан с конкретным внешним объектом и имеет доступ к его private-полям. Локальный класс виден в блоке, а анонимный удобен для одноразового переопределения поведения. Захватываемые локальные переменные должны быть final или effectively final. Это ограничение ссылки, а не глубокой изменяемости захваченного объекта. Ненужная связь с большим внешним объектом может продлить его жизнь.

## Аннотации и Class

Аннотация — метаданные. @Override проверяется компилятором, @Deprecated сообщает об устаревании. Собственная аннотация с RetentionPolicy.RUNTIME доступна отражению; SOURCE не попадает в class-файл, CLASS не обязана быть видимой runtime reflection. @Target ограничивает место применения. Class описывает тип, reflection получает поля, методы, конструкторы и вызывает их динамически. getMethods включает публичные унаследованные методы, getDeclaredMethods — объявленные в классе. Не полагайся на порядок результатов. Доступ ограничен модулями; setAccessible не гарантирует обход любой границы. Ошибки reflection обнаруживаются позже, чем прямой типизированный вызов.
