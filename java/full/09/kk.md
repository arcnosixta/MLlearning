# Object, ішкі кластар, аннотациялар және reflection

Мақсат: нысандар теңдігін, ішкі класс байланысын және типті динамикалық талдауды түсіну.

## Теңдік пен көшіру

== сілтеме сәйкестігін, equals логикалық теңдікті тексереді. Теңдік рефлексивті, симметриялы, транзитивті болуы тиіс. Тең нысандардың hashCode мәндері бірдей; бірдей хеш теңдікті дәлелдемейді. HashMap кілтінің маңызды өрістерін өзгерту іздеуді бұзады. clone — үстірт көшірме; анық көшіру конструкторы жиі түсініктірек.

GC қолжетімсіз нысандарды жинайды, бірақ ресурс жабылуын күттірмеу керек. finalize орнына AutoCloseable қолдан. native әдіске сыртқы нативті іске асыру қажет.

## Ішкі тип пен метадерек

static nested-класс сыртқы экземплярды ұстамайды; inner-класс ұстайды. Локалды және анонимді кластар effectively final айнымалыларды захваттай алады. Захватталған нысанның өзі өзгеруі мүмкін.

Аннотация — метадерек. SOURCE компиляцияға, CLASS class-файлға, RUNTIME reflection-ға арналған. @Target қолдану орнын шектейді. Class арқылы әдіс пен аннотацияны тексеруге болады. getMethods жария және мұраланған әдістерді, getDeclaredMethods сол класта жарияланғандарын береді. Модульдер private қолжетімділікті шектей алады.
