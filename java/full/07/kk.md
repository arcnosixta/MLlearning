# Мұрагерлік, полиморфизм және абстракция

Мақсат: ортақ келісім арқылы әртүрлі іске асыруды қолдану.

## Мұрагерлік келісімі

extends бір ата-аналық класты көрсетеді. «Болып табылады» қатынасын мұрагерлікпен, «құрамында бар» қатынасын композициямен сипатта. Конструкторлар мұраланбайды. super(...) ата-ана конструкторын шақырады. Абстрактілі класта күй, конструктор және дайын әдістер болуы мүмкін, бірақ оның тікелей данасы жасалмайды.

Экземпляр әдісінің override нұсқасы нақты нысан типімен таңдалады. Overload компиляция кезінде жарияланған типтер бойынша шешіледі. @Override қате сигнатураны табады. private әдіс переопределение болмайды; final тыйым салады. static әдістер мен өрістер динамикалық полиморфизмге қатыспайды.

Төмен қарай cast ClassCastException тудыруы мүмкін. instanceof арқылы тексер. Мұрагер базалық типтің қабылдайтын кірістерін шектемеуі және уәдесін бұзбауы тиіс. Көптеген cast орнына ортақ әрекетті әдіске шығар.
