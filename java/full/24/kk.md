# AWT, Swing, графика, layout және оқиғалар

Мақсат: терезелік интерфейсті құрып, оқиға ағынын бұғаттамау.

## Компоненттер

AWT Component, Container, Frame, Canvas, Graphics береді. Swing ішінде JFrame, JPanel, JButton, JLabel бар. JFrame үшін графикалық орта керек; headless режимде терезе жасалмайды. Applet — ескі браузер моделі, қазіргі сайт жариялау тәсілі емес.

FlowLayout қатарлап, BorderLayout бес аймақпен, GridLayout тең ұяшықпен, CardLayout карточка ауыстырумен орналастырады. Абсолютті координаттар шрифт пен тіл өзгергенде бұзылады. Панельдерді біріктіріп, pack қолдан.

Swing жұмысын EDT ішінде invokeLater арқылы орында. Ұзақ файл оқу интерфейсті қатырады; SwingWorker қолдан. Суретті paintComponent ішінде super шақырғаннан кейін сал. Модельді бөлек сақта, өзгергенде repaint шақыр. Graphics2D түс, шрифт, фигура, түрлендіру береді. create арқылы алынған контексті dispose жаса.
