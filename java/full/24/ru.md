# AWT, Swing, графика, layout и события

Цель: понимать устройство настольного интерфейса и не блокировать его поток обработки событий.

## Компоненты и контейнеры

AWT предоставляет базовые Component, Container, Frame, Panel, Canvas, события, шрифты и графический контекст. Swing строит более богатые компоненты: JFrame, JPanel, JButton, JLabel, JTable. Большинство Swing-компонентов рисуется средствами Java, но они всё равно взаимодействуют с оконной системой. Для интерфейса нужна среда с экраном; в headless-среде создание JFrame может выбросить HeadlessException. Applet из старых материалов — историческая браузерная модель, не способ публикации современного сайта; браузерный плагин не используется.

## Менеджеры компоновки

FlowLayout размещает компоненты последовательно, BorderLayout делит контейнер на CENTER/NORTH/SOUTH/EAST/WEST, GridLayout даёт равные ячейки, CardLayout переключает карточки. GridBagLayout позволяет сложные ограничения. Вложенные панели комбинируют правила. Абсолютные координаты через null layout ломаются при изменении размера, шрифта и языка. Используй preferred size, pack и реальные минимальные размеры, а не одну картинку на одном разрешении.

## События и EDT

ActionListener обрабатывает нажатие кнопки, MouseListener — действия мыши, KeyListener — клавиши; для команд Swing часто удобнее key bindings. Слушатель получает событие и меняет модель, затем вид обновляется. Большую часть работы с Swing выполняй на Event Dispatch Thread через SwingUtilities.invokeLater. Длительное чтение файла на EDT замораживает окно. SwingWorker переносит работу в фон; завершение и обновление UI должны вернуться в корректный поток. Не обновляй JLabel из произвольного фонового потока.

## Рисование

У Swing-компонента переопределяй paintComponent(Graphics g), сначала вызывай super.paintComponent. Не рисуй постоянное состояние через getGraphics: оно исчезнет при перерисовке. Модель хранит данные, paintComponent отображает текущее состояние; запроси repaint, а не вызывай paint вручную. Начало координат обычно слева сверху, y растёт вниз. Graphics2D поддерживает цвет, Font, Stroke, геометрические фигуры и transforms. Копию контекста из create обязательно dispose; исходный системный контекст принадлежит Swing.
