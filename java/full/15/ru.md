# Функциональные интерфейсы, лямбды и ссылки на методы

Цель: передавать операцию как значение, понимая её вход, результат и побочные эффекты.

## Целевой тип лямбды

Функциональный интерфейс имеет один абстрактный метод, не считая соответствующих публичных методов Object. @FunctionalInterface позволяет компилятору проверить это намерение. default и static методы не мешают. Лямбда не существует без целевого типа: `x -> x * 2` может соответствовать разным интерфейсам. Входные типы часто выводятся из контекста. Если тело — блок и требуется результат, нужен return. Проверяемые исключения допускаются только согласно сигнатуре целевого метода.

## Четыре базовых роли

Predicate<T> принимает T и возвращает boolean; Function<T,R> преобразует значение; Consumer<T> выполняет действие без результата; Supplier<T> производит значение без аргумента. UnaryOperator<T> и BinaryOperator<T> сохраняют тип результата. Примитивные IntPredicate, IntFunction и IntSupplier уменьшают лишнюю упаковку. Выбирай интерфейс по контракту, а не по названию метода, который удобно вызвать.

## Композиция и захват

Predicate.and/or сокращают вычисление. Function.andThen сначала выполняет текущую функцию, compose — переданную. Локальная захваченная переменная должна быть effectively final; содержимое захваченного списка при этом может меняться. Это не даёт потокобезопасности. В лямбде this относится к внешнему объекту, а не к новому экземпляру анонимного класса. Скрытые изменения внешнего состояния затрудняют повторное использование и параллельное выполнение.

## Ссылки на методы и Comparator

`String::length` обозначает вызов метода у аргумента, `printer::print` — метод конкретного объекта, `Integer::parseInt` — static-метод, `ArrayList::new` — конструктор. Совместимость проверяется с целевым интерфейсом. Comparator.comparing строит порядок по ключу, thenComparing разрешает равенство ключей. Не сравнивай числа вычитанием: возможны переполнение и неверный знак. Используй Integer.compare. Укажи политику null через nullsFirst/nullsLast, если null допустим.
