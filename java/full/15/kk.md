# Функционалдық интерфейстер және лямбдалар

Мақсат: әрекетті параметр ретінде беріп, оның келісімін түсіндіру.

## Функция типі

Функционалдық интерфейсте бір abstract әдіс бар. @FunctionalInterface оны тексереді; default және static әдістер кедергі емес. Лямбдаға мақсатты тип қажет. Predicate шартты тексереді, Function түрлендіреді, Consumer әрекет орындайды, Supplier мән жасайды. Примитив нұсқалар артық boxing-ті азайтады.

and/or шарттарды қысқаша есептейді. andThen алдымен ағымдағы функцияны, compose алдымен берілгенін орындайды. Захватталған жергілікті айнымалы effectively final болуы керек; ішкі нысан бәрібір өзгеруі мүмкін. Бұл ағын қауіпсіздігін бермейді.

String::length — аргумент нысанының әдісі, Integer::parseInt — static әдіс, ArrayList::new — конструктор. Comparator.comparing және thenComparing күрделі ретті құрады. Сандарды азайту арқылы салыстырма: толып кетуі мүмкін. Integer.compare қолдан.
