# Динамические структуры и конечные автоматы

Цель: связывать алгоритмы со структурой данных и описывать переходы состояния явной моделью.

## Узлы и динамические структуры

В Java роль указателя из низкоуровневых сборников играет ссылка. Узел списка хранит значение и next, двусвязный — ещё prev. Голова и хвост задают входы; отдельно обработай пустую структуру и единственный узел. Вставка после известного узла O(1), поиск узла O(n). Удаляя, сначала сохрани нужные ссылки, затем перестрой связи. Недостижимые узлы соберёт GC; ручного free нет. Цикл в списке мешает наивному обходу: алгоритм медленного/быстрого указателей обнаруживает его за O(n) и O(1) памяти.

## Стек, очередь и обход

Стек LIFO подходит для обратного пути, разбора скобок и DFS; очередь FIFO — для BFS и задач по поступлению. Динамический массив увеличивает вместимость с запасом, чтобы добавление было амортизированно O(1), а не копировало все данные каждый раз. В прикладном коде выбирай готовые ArrayList/ArrayDeque; реализация узлов вручную здесь учебная. Для графа отдельно храни visited, иначе цикл вызовет повторный обход. BFS на невзвешенном графе находит кратчайшее число рёбер, но не решает произвольные веса.

## Формальная модель автомата

Детерминированный конечный автомат содержит конечные состояния Q, алфавит Σ, начальное состояние, функцию переходов и принимающие состояния. Он читает вход слева направо; следующий шаг определяется текущим состоянием и символом. Пример ниже распознаёт двоичные строки, оканчивающиеся на 01. Состояния означают полезную часть уже прочитанного суффикса. Полная история строки не нужна. Неизвестный символ отклоняется, пустая строка не принимается.

## Синхронность и произведение

Синхронные автоматы меняются на общем шаге; асинхронные — по поступившим событиям с определённым порядком обработки. В произведении двух автоматов состояние — пара (q1,q2), переход обновляет обе компоненты. Это позволяет совместить независимые ограничения, но число состояний растёт как произведение. Для заказа состояние и событие могут быть enum, переход — таблица; запрещённую пару нельзя молча трактовать как успех. Для параллельных отправителей сериализуй события или защищай переход атомарно.
