# Bash: қателер, errexit және nounset

Мақсат: қате көрінетін болсын, қауіпті жалғастыру тоқтасын және бір флагқа артық сенім болмасын.

## Статус келісімі

0 сәттілік, басқа код отказты білдіреді. if, && және || осыны қолданады. $? мәнін дереу сақта: келесі команда ауыстырады. Кез келген қатеге || true қоспа; ол файл жоқтығы мен маңызды жүйе қатесін бірдей жасырады.

Өзгерісті дайындау, тексеру және қолдануға бөл. Алдымен уақытша конфиг жаса, синтаксисті тексер, содан кейін ғана ауыстыр. Транзакция жоқ болса орындалған қадамдардың откатын жоспарла.

## Флагтардың шегі

set -e кейбір өңделмеген қатеде шығады, бірақ if, while, &&/|| және pipeline контексттерінде ерекшеліктер бар. Шарт ретінде шақырылған функцияны жай шақырумен бірдей деп ойлама. Маңызды командаға анық if/return жаса.

Әдетте pipeline статусы соңғы команданікі. pipefail алдыңғы қатысушы қатесін көрсетуге көмектеседі. PIPESTATUS массивін pipeline-нан кейін бірден көшір. Бұл жартылай өзгерісті автоматты қайтармайды.

## Nounset және тест

set -u белгіленбеген айнымалыны оқуды қате етеді. Бос жол бөлек жағдай. `${name:-default}` әдепкі мән, `${name:?message}` міндетті мән үшін қолайлы. $1 оқудан бұрын $# тексер. ERR trap барлық қатені қамтымайды, EXIT cleanup бастапқы статусты сақтауы керек. Әдейі аралық қате мен бос аргументті сына; bash -n тек синтаксис қарайды.
