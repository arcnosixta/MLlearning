# Bash: шарттар, циклдер, аргументтер және read

Мақсат: кірісті тексеретін, тырнақшаларды дұрыс қолданатын және анық нәтиже беретін сценарий жазу.

## Команданы талдау

Shell команданы орындаудан бұрын айнымалы мен шаблонды ашады. `"$file"` бір аргументті сақтайды, `"$@"` барлық аргумент шекарасын сақтайды. Тырнақшасыз мән бос орынмен бөлініп, glob ретінде ашылуы мүмкін. Қарапайым пайдаланушы мәтініне eval қолданба.

Присваивание ішінде бос орын жоқ: name=value. `$(command)` stdout алады және соңғы newline таңбаларын жояды. `$?` — соңғы команда статусы; келесі команда оны өзгертеді. 0 сәттілікті білдіреді, мәтіндік нәтижеге stdout қолданылады.

## Шарт және цикл

if команда статусын тексереді. [[ ]] жолға, (( )) арифметикаға қолайлы. Сандық есепке дейін синтаксис пен диапазонды тексер. case белгіленген сөздерге ыңғайлы. for циклінде `"$@"` қолдан; ls нәтижесін сөзге бөліп файлдарды аралама.

## Оқу

`IFS= read -r line` шеткі бос орын мен backslash-ты сақтайды. IFS=, жай бөлгішке жарайды, бірақ толық CSV ережелерін орындамайды. Pipeline оң жағындағы цикл subshell ішінде жұмыс істеп, сыртқы санауышты өзгертпеуі мүмкін. Файл redirect-і циклді ағымдағы shell ішінде ұстайды. Соңғы newline жоқ жол үшін read шартына `|| [[ -n $line ]]` қосуға болады.
