# awk: поля, записи, переменные и отчёты

Цель: превратить табличный текст в проверяемый отчёт, явно определив разделители, правила числового ввода и порядок результата.

## Правило pattern-action

Программа awk состоит из правил «условие { действие }». Для каждой входной записи проверяются правила; BEGIN выполняется до чтения, END — после. `$0` содержит запись, `$1` — первое поле, NF — число полей. Отсутствие условия означает применение к каждой записи. next переходит к следующей записи, не выполняя остальные правила для текущей. Это удобнее, чем строить длинный pipeline только для доступа к нескольким полям.

По умолчанию запись обычно отделяется newline, а поля — пробельными промежутками. `-F,` или FS задаёт разделитель полей, RS — записей; OFS и ORS задают разделители вывода print. printf использует собственный формат. После присваивания отдельному полю `$0` может быть перестроен с OFS, поэтому исходное форматирование не гарантируется. Простой FS=, не делает awk полноценным CSV-парсером с quoted fields и переводами строк внутри значения.

## Счётчики и окружение

NR считает записи через все входные файлы, FNR начинает счёт в каждом файле заново. Условие NR==1 пропускает только первый общий заголовок, а FNR==1 — первый в каждом файле: выбери по формату входа. FILENAME показывает текущий источник, ARGV — аргументы awk, ENVIRON — окружение. Не печатай весь ENVIRON в отчёт: там могут быть секреты. FIELDWIDTHS — расширение GNU awk для фиксированных ширин; не рассчитывай на него в любой реализации awk.

Перед арифметикой валидируй поля: преобразование строки в число может скрыть ошибочный ввод. Установи ожидаемую локаль для воспроизводимых машинных десятичных чисел. Отличай пустое поле от нуля. При суммировании больших значений учитывай числовую модель реализации, а для точных денежных расчётов выбирай соответствующий типизированный инструмент.

## Массивы, циклы и функции

Ассоциативные массивы хорошо подходят для группировки: `sum[$1]+=$2; count[$1]++`. Цикл `for (key in array)` не обещает сортированного порядка; сортируй результат снаружи или применяй документированное расширение GNU awk. for/while обходят элементы, if выбирает обработку записи, пользовательские функции разделяют преобразования. split разбивает строку в массив, sub/gsub меняет совпадения, length и substr работают со строками, sprintf формирует значение без печати.

Не запускай system() и shell-команды, составленные из непроверенного поля журнала. Для отчёта обычно достаточно данных stdout. При ошибочном формате возвращай ненулевой код и не выдавай частичную статистику как полную. Важно продумать END: он может выполниться и после раннего exit, поэтому отметка ошибки должна блокировать публикацию итогового отчёта.

### 2. Ошибочное число

В поле grade появилась строка unknown. Как избежать превращения её в ноль и правдоподобной средней?

{{answer:2}}

<details><summary>Разбор</summary>
