# FreeIPA орталықтандырылған идентификациясы

Мақсат: ортақ есептік жазбаны нақты хост рұқсатынан ажырату.

## Қызметтер және құқық

FreeIPA каталог, Kerberos, хост пен саясат басқаруын біріктіреді; DNS және CA таңдалған схемаға қосылады. Бір пайдаланушы барлық серверде бірдей құқық алмайды. UID/GID сандық тұлғаны, топ мүшелігі рұқсат жинағын анықтайды. HBAC кіруді, sudo rules артықшылықты команданы басқарады. Жергілікті ат пен домен атының қақтығысын алдын ала тексер.

## Стенд дайындау

Бөлек сервер және клиент VM қолдан. Тұрақты FQDN, дұрыс DNS және уақыт синхронизациясын орнатудан бұрын тексер. Kerberos уақытқа тәуелді. Домен мен realm-ды саналы таңда. Сервер платформасының қолдауын және ресурс көлемін нақты нұсқа құжатынан тексер. Snapshot — жұмыс каталогының толық backup рәсімі емес.

## Клиент тексеруі

getent және id identity табылуын көрсетеді. kinit/klist билет алуды тексереді. SSH не басқа сервис өз авторизация саясатын қолданады. SSSD кеші желі жоқта көмектесе алады, бірақ offline кіру мен рұқсатты қайтару ережелері бөлек.

Оператор тобына нақты host group және сервис үшін HBAC жаса. Топтағы және топтан тыс адамды, басқа хостты тексер. Кең allow-all жаңа ереженің әсерін жасырып қалмасын. Кіру қабылданғанша жергілікті авариялық VM қолжетімділігін сақта.
