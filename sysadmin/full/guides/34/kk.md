# Docker: контейнер, Dockerfile және Compose

Мақсат: қосымшаны қайталанып жинап, тұрақты деректі контейнер данасынан бөлу.

## Образ және дана

Image қабаттар мен іске қосу конфигурациясын ұстайды. Container — өзгермелі қабаты бар процесс данасы. Ол хост ядросын қолданады, жеке VM емес. Namespace пен cgroups әртүрлі изоляция және лимит береді. Privileged режимі мен Docker socket қажетсіз кең құқық береді. Тег өзгеруі мүмкін, digest нақты мазмұнды анықтайды.

## Сборка келісімі

Dockerfile ішінде FROM негізді, WORKDIR каталогты, COPY файлды, RUN жинақтау қадамын, USER пайдаланушыны, CMD/ENTRYPOINT іске қосуды анықтайды. Exec-форма сигнал жіберуді түсініктірек етеді. Құпияны ARG/ENV не қабатқа көшірме. .dockerignore контекстті шектейді, бірақ кездейсоқ кілт жоқтығын өзің тексер.

## Сақтау және желі

БД дерегін volume не анық сыртқы қоймаға сақта. Контейнердің writable layer-і жаңа данаға автоматты көшпейді. Bind mount хост жолы және UID/GID келісімін қажет етеді. Портты 127.0.0.1-ге жариялау мен барлық интерфейске жариялау бөлек. EXPOSE портты ашпайды.

Compose сервис, желі және томды YAML-да сипаттайды. `docker compose config` подстановканы тексереді; output-та құпия болмасын. up сервис дайын деген сөз емес. Healthcheck, тәуелділік шарты және қолданба retry-ы қажет. down -v дерек томын жоя алатынын ескер. Откат бұрынғы образбен бірге дерек схемасының үйлесімділігін қамтысын.

### 2. Дайындық

</details>
