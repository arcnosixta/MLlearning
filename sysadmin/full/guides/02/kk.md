# Командалық жол және дерек ағындары

Мақсат: каталогпен жұмыс пен конвейердегі дерек бағытын түсіну.

## Оболочка және жол

pwd каталогты көрсетеді, cd оны ағымдағы оболочкада өзгертеді. Абсолютті жол / таңбасынан, салыстырмалы жол ағымдағы каталогтан басталады. cd — builtin: еншілес процесс ата-анасының каталогын ауыстыра алмайды. Бос орны бар жолды тырнақшаға ал. type және command -v команданың қайдан келетінін көрсетеді.

## Аргументтер

`"$name"` бір мәнді бір аргумент сақтайды. Тырнақшасыз бос орын мен glob аргумент санын өзгертеді. * әдетте жасырын файлды қоспайды. ls шығысын файл атауларына бөлме: атауда жаңа жол болуы мүмкін. find -print0 және NUL өңдеуін қолдан.

## Үш ағын

0 — stdin, 1 — stdout, 2 — stderr. `>` файлды обнуляет, `>>` қосады, pipe stdout-ты келесі stdin-ге береді. Қате ағыны бөлек қалады. `>all.log 2>&1` екі ағынды біріктіреді; кері рет басқа нәтиже береді. 0 статус — сәттілік. pipefail жоқта конвейер алғашқы қатені жасыруы мүмкін.
