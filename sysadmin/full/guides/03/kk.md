# Файлдар, каталогтар және сілтемелер

Мақсат: файл атауын дерекпен шатастырмай, көшіру мен жою салдарын түсіну.

## Нысан мен атау

Каталог атауды файл жүйесі нысанымен байланыстырады. ls -l қысқаша, stat толық метадерек береді. file мазмұн бойынша пішімді анықтауға көмектеседі. Кеңейтім форматты кепілдемейді. /etc конфигурацияға, /var өзгермелі дерекке, /home пайдаланушыға арналған, бірақ нақты дистрибутивті тексер.

cp тәуелсіз көшірме жасайды. mv басқа файл жүйесіне өткенде жай rename емес. Көшіруде байтпен бірге құқық, иесі және уақытты сақтау талабын анықта. -- параметрлерді файл атауынан бөледі. Операцияға дейін нақты жолдар мен файлдар жиынын тексер.

## Сілтемелер

Hard link бір inode-тың басқа атауы және бір файл жүйесінде болады. Екі атаудан өзгеріс ортақ. Symlink мақсат жолын сақтайды, басқа файл жүйесіне бара алады. Салыстырмалы мақсат сілтеме каталогынан есептеледі. Мақсат жойылса, сілтеме қалады, бірақ ашылмайды.

cmp байттарды, diff мәтінді салыстырады. Ашық, бірақ жойылған файл процесс жапқанша орын алуы мүмкін. df пен du айырмасын зертте; басқа деректі себепсіз жойма.

## Практика

### 1. Көшірме

Көшірмені өзгертіп, бастапқы файл өзгермегенін дәлелде.

{{answer:1}}

<details><summary>Шешім</summary>

cp, printf және cmp/diff қолдан. Hard link-тен айырмасын түсіндір.
</details>

### 2. Symlink

Салыстырмалы сілтемесі бар каталогты көшір.

{{answer:2}}

<details><summary>Шешім</summary>

readlink пен нақты оқуды тексер. Тек сілтемені бөлек жылжыту мақсатты өзгерте алады.
</details>

</details>
