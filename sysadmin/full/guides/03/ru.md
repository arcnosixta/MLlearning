# Файлы, каталоги и ссылки

Цель: различать имя файла и хранимые данные, выполнять копирование и удаление с понятными последствиями.

## Файл и каталог

Каталог сопоставляет имя объекту файловой системы. Метаданные Linux включают владельца, группу, режим, размер и временные отметки. ls -l показывает краткий обзор, stat — подробности, file определяет тип по содержимому и другим признакам. Расширение само по себе не задаёт формат. Корень / — начало дерева, /etc обычно хранит конфигурацию, /var — меняющиеся данные, /home — пользовательские каталоги. Реальное распределение уточняй для своего дистрибутива.

## Копирование и перемещение

cp создаёт копию данных, mv меняет расположение/имя, rm удаляет запись. При переносе между файловыми системами mv не является простым атомарным переименованием. Для административной копии важны не только байты: проверь сохранение владельца, режима, ссылок и времён по требованиям. Перед работой уточни исходный и целевой пути, особенно завершающий /. `--` отделяет параметры от имён, начинающихся с дефиса. Для нескольких файлов сначала перечисли точный набор, затем выполни действие; glob может охватить больше ожидаемого.

## Жёсткая и символическая ссылка

Жёсткая ссылка — ещё одно имя того же inode в той же файловой системе. Изменение содержимого видно через оба имени; удаление одного не обязательно удалит данные. Символическая ссылка содержит путь к цели и может пересекать границы файловых систем. Относительная цель вычисляется относительно каталога ссылки. После удаления цели symlink остаётся, но становится «битой». ln создаёт hard link, ln -s — symlink; readlink показывает сохранённую цель. Выбирай поведение программы при обходе ссылок явно.

## Проверка и восстановление

cmp сравнивает байты двух файлов, diff показывает текстовые различия, sha256sum удобен для контрольной суммы. Совпадение имени не доказывает совпадение содержимого. Удалённый, но ещё открытый процессом файл может занимать место до закрытия дескриптора. Поэтому df и du иногда показывают разные картины; это повод исследовать открытые файлы, а не удалять другие каталоги наугад. Проверяемая копия и опыт восстановления важнее единственного сообщения «копирование завершено».
