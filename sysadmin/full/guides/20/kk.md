# Bash: функциялар, массивтер және кітапханалар

Мақсат: сценарийді анық келісімі бар функцияларға бөліп, аргумент шекарасын сақтау.

## Функция келісімі

Функция өз $1 және "$@" аргументтерін алады. Алдымен санын және мәнін тексер. return мәтін емес, exit status береді. Нәтижені stdout, диагностиканы stderr арқылы жібер. Артық debug мәтіні командалық подстановка нәтижесін бұзады.

local шақыру аймағын шектейді, бірақ Bash динамикалық көріну ережесін қолданады: шақырылған функция сыртқы функцияның local мәнін көре алады. Жасырын ортақ атауға сүйенбе. Subshell ішіндегі айнымалы өзгерісі ата-анаға қайтпайды.

## Массивтер

`items=("first item" "second")` екі элемент жасайды. `"${items[@]}"` әр элементті жеке, ал `"${items[*]}"` бір жол етіп береді. `${#items[@]}` қойылған элементтерді санайды; индекстер бос аралықты болуы мүмкін. Ассоциативті массив реті тұрақты емес, есепке кілттерді сұрыпта. Пайдаланушы мәнін тексерусіз арифметикалық индекс қылма. Bash сценарийін sh арқылы орындау синтаксисті өзгерте алады.

## Кітапхана

Рекурсия базалық жағдайға жақындауы керек; үлкен тереңдік shell үшін қымбат. source файлды ағымдағы shell-де толық орындайды. Сенімді жол, функция префиксі және үстіңгі деңгейде жанама әрекетсіз код қолдан. Main бөлігі кітапханадан бөлек болсын. Қайта source күтпеген әсер қоспасын.
