# Пайдаланушылар, топтар және sudo өкілеттігі

Мақсат: қажетті ең аз құқықты беріп, процесс жеке басы мен ортасын ажырату.

## Идентификация

Linux сандық UID/GID және қосымша топтарды тексереді. id нақты сессияны көрсетеді. getent NSS көздерін, соның ішінде сыртқы каталогты қолданады. Топ қосылған соң ескі сессия автоматты жаңармауы мүмкін: жаңа кіруде тексер. Қызмет пайдаланушысы сервисті оқшаулауға арналған.

## su және sudo

su басқа пайдаланушы оболочкасын ашады. sudo саясаттағы нақты әрекетті орындайды, sudo -l рұқсатты көрсетеді. cd ағымдағы shell builtin-і болғандықтан sudo cd ата-ана каталогын өзгертпейді. Толық root-shell орнына нақты қызмет операциясын рұқсат ет.

sudoers-ті visudo арқылы өзгерт. Бағдарлама жолы, аргумент, runas және конфигурация иесін тексер. Редактор не интерпретатор кең құқық бере алады. Пайдаланушы өзгерте алатын скриптті root ретінде іске қосу минималды құқық емес. Есептік жазбаны өшіргенде сессия, кілт, cron және файл иелігін де тексер.

## Практика

### 1. Топ

Екі пайдаланушыға ортақ жоба каталогын бер.

{{answer:1}}

<details><summary>Шешім</summary>

Жаңа сессияда id, каталог тобы және режимін тексер. World-write қоспа. setgid пен default ACL қажеттілігін анықта.
</details>

### 2. Шектеулі sudo

Тек бір қызметті қайта қосуға рұқсат бер.

Нақты команда мен аргумент, visudo және қарсы сынақ керек. Unit өзгерту құқығын берме.
</details>
