# OpenSSL сертификат орталығы және Nginx HTTPS

Мақсат: шифрлау, сертификатқа сенім және сервер атының сәйкестігін бөлек тексеру.

## Сенім моделі

Жеке кілт иесінде қалады, ашық кілт сертификатта болады. Клиент қолтаңба тізбегін, мерзімді, мақсатты және атын тексереді. Өздігінен қол қойылған сертификатқа барлық клиент автоматты сенбейді. DNS аты Subject Alternative Name арқылы тексеріледі. Сенім қатесін тексеруді өшірумен шешпе. CA жеке кілті бүкіл оқу иерархиясы атынан сертификат бере алады, оны бөлек қорға.

## PKI және сервер

Бөлек VM-де оқу CA, server key және нақты SAN бар CSR жаса. CA үшін serial, мерзім, қайтару және backup саясатын белгіле. Түбір сертификатты тек оқу клиентіне сенімді ет. CSR ішінде жеке кілт жоқ.

Nginx server блогында listen 443 ssl, server_name, сертификат және кілт жолы болады. Қажет intermediate тізбегін дұрыс ретпен бер. ssl атауы тарихи, жаңа орнатуда заманауи TLS қолданылады. `nginx -t` кейін ғана reload жаса.

## Қабылдау сынағы

SNI тиісті виртуалды сайтты таңдауға көмектеседі. openssl s_client арқылы цепочка мен атын, curl --cacert арқылы нақты сенімді тексер. -k қорытынды дәлел емес. Дұрыс/қате ат, мерзімі өткен және intermediate жоқ нұсқаларды сына. Автоматты продление сертификат жаңарып, сервис оны қолданғаннан кейін ғана дәлелденеді.
