# Мекенжай, маршрут және арна диагностикасы

Мақсат: желідегі істен шығу қабатын тауып, өлшеуді қайталай алу.

## Мекенжай мен жол

ip -br link интерфейсті, ip -br address адрес/префиксті көрсетеді. /24 — желінің 24 биті. ip neigh ARP/NDP көршісін тексеруге көмектеседі. Link up қашық қызметтің жұмысын дәлелдемейді.

Маршрут next hop пен интерфейсті анықтайды. Таңдалған кестеде нақтырақ префикс басым; policy routing басқа кесте таңдай алады. ip route, ip rule және ip route get нақты жолды түсіндіреді. Жауаптың кері маршруты да қажет.

## Тексеру мен өлшеу

Интерфейс, адрес, шлюз, маршрут, порт, қолданба ретін ұстан. Ping тек ICMP-ты тексереді. ss -lntup bind адресін көрсетеді; 127.0.0.1 қызметі сыртқа тікелей ашылмайды. DNS пен IP байланысын бөлек тексер.

iperf3 екі белгілі түйіннің арнасын өлшейді. Бағыт, ағын саны, уақыт және жүктемені бекіт. RTT, жоғалу және throughput бөлек. MTU үлкен дерекке әсер етуі мүмкін. Бір нәтиже тұрақты кепіл емес.
