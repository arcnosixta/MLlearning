# Bash: redirect және жеке файл дескрипторлары

Мақсат: дерек пен диагностиканы бөлек бағыттап, ашық дескриптордың өмірін басқару.

## Ағындар

0 — stdin, 1 — stdout, 2 — stderr. Олар міндетті түрде пернетақта мен экран емес. > файлды қысқартып ашады, >> соңына қосады, < кіріс береді. Қате мәтінін >&2 арқылы шығар; машиналық нәтижемен араластырма. Pipeline әдетте тек stdout жалғайды, stderr бөлек қалады. |& оны да біріктіреді.

## Рет әсері

Redirect солдан оңға орындалады. `>all.log 2>&1` екі ағынды файлға береді. `2>&1 >out.log` stderr-ді бұрынғы stdout-та қалдырады. 2>&1 ағымдағы тағайындауды көшіреді, кейінгі өзгеріске автоматты ермейді.

`filter file >file` бастапқы файлды команда басталмай тұрып босатуы мүмкін. Бөлек уақытша файлға жаз, тексер, кейін келісілген тәсілмен ауыстыр. Маңызды конфигте құқық, иесі және MAC меткасы да сақталуы керек.

## Дескриптор өмірі

`exec 3<input.txt` кірісті ағымдағы shell-де ашады. read <&3 сол файлдан оқиды; `exec 3<&-` жабады. exec командасыз shell redirect-ін өзгертеді, командамен процесті алмастырады. Қажетсіз дескрипторды бала процеске қалдырма. Quoted heredoc ішкі подстановканы тоқтатады; here-string соңына newline қосады.
