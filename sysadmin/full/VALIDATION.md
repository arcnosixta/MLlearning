# Проверка доработок курсов — 27 октября 2026 года

Материалы сохраняют исходные 106 видео, 35 разборов Linux и 26 глав Java.
Добавлены 106 отдельных учебных целей, пять маршрутов, 35 двуязычных сценариев
с объяснениями и архивы примеров/текстов. Цели и сценарии — авторские задания
по темам, не полученные стенограммы YouTube.

## Что проверяется

- Неполные главы, отсутствующие исходники, повторённые и нераспределённые видео
  отклоняются до генерации новых данных курса.
- Индексы не содержат полный HTML/код: Java — 20 317 байт вместо 322 231;
  Linux — 67 686 байт вместо 652 818 для полного каталога с новыми целями и сценариями.
  Размеры относятся к несжатому JSON этой сборки. Legacy teaching.json не
  запрашивается на страницах полных курсов.
- Сбой дополнительного Java-индекса не отключает Linux и вводные ссылки;
  неудачная загрузка главы повторяется по кнопке после восстановления сети.
- Фильтры сохраняются через Back, reload и фактическое переключение языка.
  Маршрут Bash показывает 32 исходных видео; сброс возвращает весь список106.
- Отмена отметки не стирает ответы. Старые отметки видео не преобразуются
  автоматически в выполненную практику. Экспорт/импорт сохраняет оба вида.
- Все35 сценариев проверяются с выбором неверного и верных ответов, сохранением
  результатов, проверкой диапазона/типа значений и отсутствием автоматических
  отметок освоения. Прежние экзамены используют прежние банки и идентификаторы.
- Клавиатурная навигация фокусирует заголовок новой страницы; загрузка видео
  передаёт фокус плееру. Самопроверка помещается в ширину320 px.
- Оба ZIP-архива содержат все ожидаемые примеры; контрольные суммы каждого
  файла сверяются с MANIFEST.sha256. Примеры не смешиваются в один класс Main.

Основные команды: `full_source_check.py`, `course_bundle_check.py`,
`verify_java_full.py`, `verify_sysadmin_full.py`, `browser_course_loading.py`,
`browser_course_study.py`, `browser_course_review.py`, оба браузерных теста
полных курсов. Отдельно проверяются legacy-хранилище, локализация, учебные
разборы и интерфейс; ядра экзаменов запускаются в Node.

Ограничения прежние: видео остаются на стороне YouTube, воспроизведение зависит
от его доступности. Проверка iframe использует тестовый ответ, а не выдаёт его
за просмотр всех видео. Bash-примеры проверяются на учебных данных, включая
реальную проверку временного сертификата OpenSSL; серверные службы, реальные
диски, firewall и VPN на хосте не изменяются. Java компилируется с `--release 17`;
GitHub Actions дополнительно выполняет проверки на JDK 17.
