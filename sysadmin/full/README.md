# Системное администрирование: весь плейлист

Полный исходный плейлист «Администрирование Линукс (Linux)» канала
**«Новая образовательная система»**:
[106 видео на YouTube](https://www.youtube.com/playlist?list=PLYl91BhaOf-kkXWweBzgOw555he6S7SUs).
Состав проверен 27 октября 2026 года: вводный урок и уроки 1–105,
общая длительность 136 919 секунд (38 часов 1 минута 59 секунд).
Ссылка пользователя — урок 13 о DAC файлов, позиция 14 в плейлисте.

Публичный маршрут: `#sysadmin/full`; отдельное видео: `#sysadmin/topic/001` … `106`.
В каталоге и в старом курсе Linux есть ссылка «106 видео · весь плейлист».

## Продолжение обучения

У каждого из 106 видео теперь есть собственная цель и проверка результата на
русском и казахском (`briefs.json`). Это наши учебные ориентиры по подтверждённой
теме видео; они не объявляются расшифровкой авторской демонстрации.

Для выбора направления доступны пять маршрутов: основы Linux, автоматизация,
сети и защита, прикладные сервисы, хранение и расследование. Видео в выбранном
наборе сохраняют порядок автора. Показаны суммарная длительность и следующий
непройденный шаг. Поиск и фильтры записываются в адрес страницы: они сохраняются
после Back, перезагрузки, смены языка и при отправке ссылки другому человеку.

Просмотр 106 видео и выполнение практики 35 тем отмечаются отдельно. Ошибочную
отметку можно снять, сохранив текст решения. Прежние ответы к каждому видео
остаются независимыми: переход к связанному видео не перезаписывает их.

В `#sysadmin/review` находится 35 диагностических сценариев, по одному на тему.
Тот же вопрос доступен рядом с практикой. После ответа открывается объяснение;
результат сохраняется при смене языка и входит в резервную копию. Самопроверка
не выдаёт официальную оценку и не отмечает видео/практику выполненными.

Архив `sysadmin-full/study.zip` содержит все 35 примеров, ожидаемые результаты,
RU/ҚАЗ тексты, исходные ссылки, цели видео и сценарии. README объясняет запуск
в Linux/WSL/Git Bash и зависимость OpenSSL. MANIFEST.sha256 позволяет проверить
байты после распаковки. Видео в архив не скачиваются; личный прогресс экспортируется
отдельно через раздел данных.

## Что включено

- Все 106 оригинальных видео с сохранёнными названиями, автором, порядком,
  длительностью и прямыми ссылками. Плеер загружается по нажатию кнопки.
- 35 тематических разборов на русском и казахском. Они объединяют связанные
  видео и добавляют самостоятельное объяснение, практический маршрут и ошибки.
- 105 практических заданий к тематическим блокам, подсказки и разборы.
- 35 скачиваемых Bash-примеров с ожидаемым выводом. Они работают без root
  на учебных данных; пример PKI требует OpenSSL и создаёт только временный сертификат.
- Поиск, фильтр по теме/прогрессу, переходы между видео и сохранение решений.

Видео остаются у автора на YouTube, не скачиваются и не перепубликуются как
наши файлы. Субтитры получить не удалось: текстовые разборы не выдаются за
стенограммы или пересказ всех реплик автора. Полнота исходного материала
обеспечивается доступом к каждому полному видео. Для просмотра нужен YouTube;
доступность зависит от автора, региона и сети, у каждого урока есть прямая ссылка.

## Порядок обучения

Для последовательного просмотра иди по исходному списку 001–106.
Тематический фильтр помогает собрать связанные части, записанные автором
в разные моменты. Отдельный текстовый разбор повторяется у видео одного блока;
это один связанный модуль, а не несколько разных стенограмм.

1. Подготовь VM и прочитай цель тематического блока.
2. Посмотри полное видео, выпиши команды и условия его стенда.
3. Сверь версии с официальной документацией и повтори на своей учебной машине.
4. Выполни Bash-пример и самостоятельную задачу, сохрани наблюдения.
5. Проверь результат/откат и только затем отметь видео пройденным.

Видеоуроки о Nmap, SUID и защите изучаются на собственном изолированном стенде.
PPTP, старые названия SSL и другие исторические решения сохранены в исходном
видеоряде; текст поясняет ограничения и современные варианты. Скачиваемые
демонстрации не устанавливают службы и не меняют host firewall, PAM, sudoers
или диски. Реальные серверные лабораторные требуют отдельной Linux VM.

не перенумерованы и его пропуск «Bash часть 4» не выдуман как отдельное видео.

## Исходники и данные

`playlist.json` — снимок публичных метаданных YouTube, `groups.json` — связи
видеоуроков с разборами и прежними 13 неделями. В `guides/01` … `35` находятся
`ru.md`, `kk.md`, `lab.sh`, `output.txt`. `{{example}}` вставляет один проверяемый
пример в оба языка, `{{answer:1}}` … `3` превращаются в поля для решения.
Markdown очищается при сборке; пользовательский текст выводится как значение
поля, а не HTML. iframe создаётся только из проверенного YouTube ID.

Прогресс хранится отдельно: `learning.completed` со значениями
`sysadmin-full/001`, ответы — `learning.practice['sysadmin-full/001/1']`.
Практика темы: `learning.completed` со значением `sysadmin-practice/01`.
Сценарии: `learning.review['sysadmin/01']` содержит целочисленный выбор 0–2;
неизвестные вопросы и неверные значения резервной копии отклоняются целиком.
Ответы разных видео независимы, включая видео с общим тематическим разбором.
Переключение языка сохраняет решение. Экспорт/импорт использует прежний раздел
данных. Старые 13 модулей, 65 вопросов и сохранённые попытки экзаменов не меняются.

## Сборка и проверки

```sh
python scripts/build.py
python tests/verify_sysadmin_full.py
python tests/full_source_check.py
python tests/course_bundle_check.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
# В другом терминале при работающем сервере:
python tests/browser_sysadmin_full.py
python tests/browser_course_loading.py
python tests/browser_course_study.py
python tests/browser_course_review.py
```

В Windows при установленном Edge: `$env:PLAYWRIGHT_CHANNEL='msedge'`.
Для Bash-примеров используется Git Bash, в Linux — Bash. Серверные службы,
полноценные VM и внешний YouTube-плеер автоматически не поднимаются:
проверяются исходные ID, отложенная загрузка нужного iframe, учебные данные,
сохранение, скачивание и мобильная вёрстка. Реальные сервисные конфигурации
проверяются отдельно по условиям лабораторной.
