## Полный курс Java по учебным материалам

Публичный [курс Java из 26 глав](https://mllearning-arcnosixta.kiregami.chatgpt.site/#java/full) ([программа](java/full/README.md)) на русском и казахском:
от JDK и алгоритмов до многопоточности, JDBC, сетей, XML, паттернов и Swing.
В каждой главе — теория, запускаемый `Main.java`, ожидаемый вывод и три задачи
с полями для собственного решения и раскрываемыми разборами: всего 78 задач.
Отдельно приложена Maven-лабораторная с TestNG и Log4j2.

После сборки открой `/#java/full`. Полные главы доступны из каталога, программы
Java, соответствующих недель и углублённых модулей. Решения и отметки завершения
сохраняются на устройстве и включаются в существующий экспорт данных.
Семестр из 14 недель и его экзамены сохраняют прежние адреса и идентификаторы.

```sh
python scripts/build.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
# Открыть http://127.0.0.1:8765/#java/full
```

Материалы PDF/PPT использованы для определения тем и сверки содержания;
оригинальные файлы и полный извлечённый текст не публикуются.
[Покрытие материалов и порядок обучения](java/full/README.md),
[результаты проверки](java/full/VALIDATION.md).

Интерфейс «От первой строки до сессии»: графитовая главная с пошаговым примером Java, каталог направлений, светлая область чтения и карта знаний на страницах программ. Узлы карты отражают завершение основных уроков; завершённые дополнительные разборы считаются отдельно. В программах Java и четырёх дополнительных курсов доступны переключение маршрута/списка и точки перехода к РК и сессии.

[Мой прогресс](https://mllearning-arcnosixta.kiregami.chatgpt.site/#progress) показывает шесть учебных путей, продолжение занятий и число завершённых контролей. [Подготовка к контролю](https://mllearning-arcnosixta.kiregami.chatgpt.site/#prepare) объединяет 15 проверок по пяти дисциплинам и ссылки на историю результатов. Для ML доступны вопросы и лабораторные по темам, а также итоговый проект. Данные остаются локальными; экспорт, импорт и удаление доступны в [разделе данных](https://mllearning-arcnosixta.kiregami.chatgpt.site/#data).

`studio.js` отвечает за новые маршруты, оглавление и переход к практике, интерактивный пример, карты и движение; `studio.css` задаёт общие цвета, адаптацию и стили чтения. Анимации используют Web Animations API, CSS и IntersectionObserver без сторонней библиотеки. `prefers-reduced-motion` отключает движение, а во время контроля нет анимации входа. Пример на главной иллюстрирует три заранее определённые операции, произвольный Java-код в браузере не запускается. Указатель последнего открытого урока хранится отдельно в `imlearning-last-route`, очищается вместе с локальными данными и не входит в учебную резервную копию.

Переходы между разделами используют View Transition API: уходящая страница растворяется со сдвигом, следующая раскрывается за 650 мс. Если API недоступен, используется последовательный выход/вход через Web Animations API. Главный заголовок появляется по строкам, секции раскрываются при прокрутке; декоративное свечение двигается отдельно от элементов управления. Быстрый повторный переход отменяет предыдущую анимацию. В действующей экзаменационной попытке и при `prefers-reduced-motion` переходы выключены.

Кнопка звука в шапке включает оригинальную композицию Orbit. Музыка продолжает играть при переходах внутри сайта; громкость и выбор сохраняются отдельно в `imlearning-sound-v1`. После полной перезагрузки нужно снова нажать кнопку воспроизведения. Аудио не загружается до включения. Панель настроек содержит паузу и громкость; удаление локальных данных останавливает музыку и сбрасывает настройки. Исходник композиции и описание: [audio/README.md](audio/README.md).

Практика открывается в боковой панели с удержанием фокуса и закрытием через Escape. Панель использует те же упражнения и поля, что и урок: сохранение ответов продолжается, а после закрытия задания возвращаются на своё место.

Проверка нового интерфейса: `python tests/browser_studio.py` при запущенном локальном сервере. Она проверяет RU/ҚАЗ, шаги кода, карту и переключение вида, прогресс и продолжение, ссылки на результаты, отключение движения и ширины 320–1920 px. Проверка включена в GitHub Actions.

`python tests/browser_motion.py` дополнительно проверяет настоящее воспроизведение (время аудио растёт), продолжение музыки при навигации, ошибки загрузки, оба варианта переходов и системное отключение движения. Общий `tests/browser_ready.py` дожидается готовности нужного маршрута, чтобы проверки не читали уходящую страницу во время анимации.

Каталог объединяет шесть направлений: базовый Java, Go, 1С, углублённый Java, системное администрирование и машинное обучение. Новый дизайн с поиском, фильтрами и адаптацией для телефона. Четыре новых курса содержат 52 двуязычные учебные недели и 260 вопросов: теория, скачиваемые примеры, практика, тренажёр ответов и контроль с таймером.

## Запуск и проверка сайта

Нужен Python 3.11+.

```sh
python -m pip install -r requirements.txt
python scripts/build.py
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Открой [локальную программу ML](http://127.0.0.1:8765/#course). Сборка создаёт статические файлы в `dist/`, включая отдельные пакеты недель. Материалы хранятся в `ml/weeks/`, `ml/project/`, `java/`, `tracks/`, `sysadmin/` и `teaching/`. Настройки публикации Sites заданы в `.openai/hosting.json`.

```sh
python tests/verify_ml.py
python -m pip install playwright
python -m playwright install chromium
python tests/browser_locale.py
python tests/browser_storage.py
```

Браузерные проверки используют запущенный локальный сервер. Полный список проверок см. в [GitHub Actions](.github/workflows/verify.yml).
