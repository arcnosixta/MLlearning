# Новые направления / Жаңа бағыттар

Каждый курс состоит из 13 учебных недель на русском и казахском языках. В модуле: три раздела теории, разбираемый пример, ожидаемый результат, самостоятельное задание с критериями, тренажёр короткого ответа, пять тестов и личная заметка. Это учебная программа для повторения; содержание конкретного университетского контроля уточняйте по своему силлабусу.

Әр курс 13 оқу аптасынан тұрады және орысша, қазақша беріледі. Модульде теория, талданған мысал, күтілетін нәтиже, өлшемдері бар тапсырма, қысқа жауап жаттығуы, бес тест және жеке жазба бар. Университет бақылауының нақты мазмұнын өз силлабусыңызбен салыстырыңыз.

## РК и сессия / РК және сессия

| Контроль / Бақылау | Недели / Апталар | Вопросы / Сұрақтар | Минуты / Минут |
| --- | --- | --- | --- |
| РК-1 | 1–7 | 30 из 35 / 35-тен 30 | 45 |
| РК-2 | 8–13 | 30 из 30 / 30-дан 30 | 45 |
| Пробная сессия / Сынақ сессиясы | 1–13 | 60 из 65 / 65-тен 60 | 90 |

Порядок вопросов перемешивается, каждая неделя соответствующего диапазона представлена. РК-2 использует все 30 вопросов второй половины курса. На странице курса и после 7-й/13-й недели есть ссылки на контроль. Контроль доступен для самостоятельной подготовки независимо от отметок прохождения.

Сұрақтар араластырылады және тиісті ауқымның әр аптасы қамтылады. РК-2 екінші бөлімнің барлық сұрағын қолданады. Бақылауға курс бетінен және 7/13-апта соңынан өтуге болады. Өткен апта белгісіне қарамастан жаттығуға рұқсат бар.

Ответы и абсолютное время окончания сохраняются при перезагрузке. При возвращении просроченная попытка завершается автоматически. После отправки доступны балл, правильные ответы, объяснения и ссылки на темы ошибок. Это учебные тесты, а не официальная аттестация; время устройства и localStorage не защищены от намеренной подмены. Хранятся последние десять попыток каждого курса.

Жауап пен аяқталу уақыты қайта жүктегенде сақталады. Бетке оралғанда мерзімі өткен талпыныс автоматты аяқталады. Нәтижеде ұпай, дұрыс жауап, түсіндірме және қайталау сілтемесі бар. Бұл ресми аттестация емес, оқу тесті. Әр курстың соңғы он талпынысы сақталады.

Прежние `exam/mid` (15 вопросов / 20 минут, недели 1–3) и `exam/final` (30 / 40, недели 1–6) сохранены для совместимости со старыми ссылками, активными попытками и историей. Они явно помечены как прежний формат. `track-config.js` — общий источник правил для хранения и интерфейса. Новые маршруты: `#track/<course>/exam/rk1`, `/rk2`, `/session`.

Бұрынғы `exam/mid` және `exam/final` сілтемелері, белсенді талпыныстар мен тарих сақталады. Олар бұрынғы пішім деп белгіленген. Жаңа жолдар: `exam/rk1`, `exam/rk2`, `exam/session`.

## Выполнение / Орындау

- **Go:** Go 1.22+, `go run main.go`. Только стандартная библиотека. Сетевой пример использует локальный `httptest`, внешний сервис не нужен.
- **Java:** JDK 17+, `javac Main.java`, затем `java Main`. Примеры самодостаточны; модуль архитектуры объясняет JDBC, но запускаемый пример использует память и не требует БД.
- **1С:** нужна платформа 1С:Предприятие 8.3 и отдельная учебная база. Для каждого фрагмента указаны модуль и необходимые метаданные. BSL проверен по структуре материалов, но не выполнялся: платформа 1С в среде проверки отсутствует. Имена метаданных учебные, их нужно создать согласно уроку.
- **Linux:** учебная VM с Bash и GNU coreutils; systemd и сетевые утилиты нужны для соответствующих практических заданий. Скачиваемые примеры используют временные файлы и диагностические данные; сетевой пример содержит явно обозначенную автономную модель. Эти модели не заменяют диагностику реального сервера.

Браузер проверяет введённые ответы по заданным вариантам, а не выполняет произвольный код. Скачайте пример и запустите в нужной среде. Для 1С учитывайте контекст формы, сервера и конфигурации.

Браузер енгізілген жауаптарды тексереді, еркін кодты орындамайды. Мысалды жүктеп, тиісті ортада іске қосыңыз. Go 1.22+, Java JDK 17+, Linux оқу VM қажет. 1С үшін 8.3 платформасы, оқу базасы және сабақта көрсетілген метадеректер керек; тексеру ортасында 1С іске қосылмады.

## Данные и проверка / Деректер және тексеру

`tracks/catalog.json` — каталог; `<course>/01.json`…`13.json` — материалы; `<course>/examples/` — исходники для скачивания. Поле `source` каждого урока ведёт на первичную документацию: Go, 1С, dev.java / Java API, GNU, systemd, OpenSSH.

Локальные записи находятся в `MLStore.tracks.<course>` и не пересекаются с Java-семестром или двумя путями ML. Экспорт включает все направления. Старые копии версии 1 принимаются; отсутствующие разделы создаются пустыми. Импорт ограничен 16 МиБ, формат и принадлежность вопросов курсу проверяются до изменения данных.

Жергілікті жазбалар курс бойынша бөлек сақталады. Экспорт барлық бағытты қамтиды. Ескі 1-нұсқа көшірмелері қабылданады; жоқ бөлімдер бос жасалады. Импорт шегі — 16 МиБ. Браузер деректерін тазаламас бұрын көшірме жүктеп алыңыз.

```sh
python scripts/build.py
python tests/verify_tracks.py
node tests/track_core_check.js
python -m http.server 8765 --directory dist
# В другом терминале / Басқа терминалда:
python tests/browser_tracks.py
```

Проверка примеров запускает Go и Java, сверяет вывод и соответствие скачиваемых файлов материалам. Bash выполняется в Linux CI; в Windows проверяется синтаксис через Git Bash. Проверка браузера проходит 104 локализованные страницы, поиск, фильтры, независимость данных, восстановление попытки, оценивание, истечение таймера и мобильный экран.


К каждой неделе добавлен двуязычный учебный разбор: словарь, пошаговый пример, ошибка и два упражнения с решениями. Перед программой доступен отдельный вводный урок. Подробнее: [teaching/README.md](../teaching/README.md). Эти материалы не меняют состав вопросов РК и сессии.

Әр аптаға сөздік, қадамдық мысал, қате және шешімі бар екі жаттығулы оқу талдауы қосылды. Бағдарлама алдында жеке кіріспе сабақ бар. РК мен сессия сұрақ құрамы сақталды.
