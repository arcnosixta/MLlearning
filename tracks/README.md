# Новые направления / Жаңа бағыттар

Каждый курс состоит из шести модулей на русском и казахском языках. В модуле: три раздела теории, разбираемый пример, ожидаемый результат, самостоятельное задание с критериями, тренажёр короткого ответа, пять тестов и личная заметка. Это учебная программа для повторения; содержание конкретного университетского контроля уточняйте по своему силлабусу.

Әр курс алты модульден тұрады және орысша, қазақша беріледі. Модульде теория, талданған мысал, күтілетін нәтиже, өлшемдері бар тапсырма, қысқа жауап жаттығуы, бес тест және жеке жазба бар. Университет бақылауының нақты мазмұнын өз силлабусыңызбен салыстырыңыз.

| Модуль | Go | 1С | Java: углублённый | Linux / системное администрирование |
| --- | --- | --- | --- | --- |
| 1 | Типы, условия, циклы | Платформа и встроенный язык | Generics, wildcard, PECS | Файлы и права |
| 2 | Функции, errors, defer | Справочники и ссылки | Контракты и неизменяемость | Процессы, systemd, журналы |
| 3 | Структуры и интерфейсы | Документы и движения | Stream и Optional | DNS, сеть, порты |
| 4 | Срезы, map, тесты | Запросы и виртуальные таблицы | Executor и Future | Хранение и восстановление |
| 5 | Goroutine, channel, context | Управляемые формы | NIO и ресурсы | SSH и доступ |
| 6 | HTTP, JSON, httptest | Транзакции и права | Архитектура и границы JDBC | Автоматизация и runbook |

После третьего модуля доступна промежуточная проверка: 15 вопросов, 20 минут. Итоговая проверка: 30 вопросов, 40 минут. Порядок вопросов перемешивается; ответы и абсолютный срок окончания сохраняются при перезагрузке. Просроченная попытка завершается при возвращении на страницу. Разбор показывает правильные ответы, объяснения и темы для повторения. Хранятся последние десять попыток каждого курса.

Үшінші модульден кейін: 15 сұрақ, 20 минут. Қорытынды бақылау: 30 сұрақ, 40 минут. Сұрақтар араластырылады; жауаптар мен аяқталу уақыты қайта жүктегенде сақталады. Мерзімі өткен талпыныс бетке оралғанда аяқталады. Талдауда дұрыс жауап, түсіндірме және қайталау тақырыбы көрсетіледі. Әр курстың соңғы он талпынысы сақталады.

## Выполнение / Орындау

- **Go:** Go 1.22+, `go run main.go`. Только стандартная библиотека. Сетевой пример использует локальный `httptest`, внешний сервис не нужен.
- **Java:** JDK 17+, `javac Main.java`, затем `java Main`. Примеры самодостаточны; модуль архитектуры объясняет JDBC, но запускаемый пример использует память и не требует БД.
- **1С:** нужна платформа 1С:Предприятие 8.3 и отдельная учебная база. Для каждого фрагмента указаны модуль и необходимые метаданные. BSL проверен по структуре материалов, но не выполнялся: платформа 1С в среде проверки отсутствует. Имена метаданных учебные, их нужно создать согласно уроку.
- **Linux:** учебная VM с Bash и GNU coreutils; systemd и сетевые утилиты нужны для соответствующих практических заданий. Скачиваемые примеры используют временные файлы и диагностические данные; сетевой пример содержит явно обозначенную автономную модель. Эти модели не заменяют диагностику реального сервера.

Браузер проверяет введённые ответы по заданным вариантам, а не выполняет произвольный код. Скачайте пример и запустите в нужной среде. Для 1С учитывайте контекст формы, сервера и конфигурации.

Браузер енгізілген жауаптарды тексереді, еркін кодты орындамайды. Мысалды жүктеп, тиісті ортада іске қосыңыз. Go 1.22+, Java JDK 17+, Linux оқу VM қажет. 1С үшін 8.3 платформасы, оқу базасы және сабақта көрсетілген метадеректер керек; тексеру ортасында 1С іске қосылмады.

## Данные и проверка / Деректер және тексеру

`tracks/catalog.json` — каталог; `<course>/01.json`…`06.json` — материалы; `<course>/examples/` — исходники для скачивания. Поле `source` каждого урока ведёт на первичную документацию: Go, 1С, dev.java / Java API, GNU, systemd, OpenSSH.

Локальные записи находятся в `MLStore.tracks.<course>` и не пересекаются с Java-семестром или двумя путями ML. Экспорт включает все направления. Старые копии версии 1 принимаются; отсутствующие разделы создаются пустыми. Импорт ограничен 8 МиБ, формат и принадлежность вопросов курсу проверяются до изменения данных.

Жергілікті жазбалар курс бойынша бөлек сақталады. Экспорт барлық бағытты қамтиды. Ескі 1-нұсқа көшірмелері қабылданады; жоқ бөлімдер бос жасалады. Импорт шегі — 8 МиБ. Браузер деректерін тазаламас бұрын көшірме жүктеп алыңыз.

```sh
python scripts/build.py
python tests/verify_tracks.py
python -m http.server 8765 --directory dist
# В другом терминале / Басқа терминалда:
python tests/browser_tracks.py
```

Проверка примеров запускает Go и Java, сверяет вывод и соответствие скачиваемых файлов материалам. Bash выполняется в Linux CI; в Windows проверяется синтаксис через Git Bash. Проверка браузера проходит 48 локализованных страниц, поиск, фильтры, независимость данных, восстановление попытки, оценивание, истечение таймера и мобильный экран.
