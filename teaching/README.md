# Учиться с нуля / Нөлден үйрену

97 существующих уроков получили индивидуальные учебные разборы. Добавлены семь отдельных вводных уроков: ML, блокноты, Java, Go, 1С, углублённая Java и Linux. Основной план — 24 ML-урока, 7 практикумов, 14 недель Java и 52 недели остальных курсов — сохраняет нумерацию. Вводные уроки идут перед планом, разборы дополняют каждую тему.

97 бұрынғы сабаққа жеке оқу талдауы қосылды. Жеті кіріспе сабақ: ML, блокнот, Java, Go, 1С, терең Java және Linux. Негізгі жоспар нөмірі сақталады; кіріспе жоспарға дейін, талдау әр тақырыппен бірге беріледі.

В каждом разборе есть объяснение механизма, словарь, пошаговый конкретный пример, распространённая ошибка и два задания. Первое выполняется с опорой, второе переносит идею на другой случай. Подсказка и объяснённое решение открываются отдельно. Всего 208 упражнений; это письменная самостоятельная практика, автоматическая оценка произвольного ответа не выполняется. Отметка «Я могу объяснить решение» — самооценка студента.

Әр талдауда механизм түсіндірмесі, сөздік, қадамдық мысал, жиі қате және екі тапсырма бар. Алғашқысы көмекпен, екіншісі идеяны басқа жағдайға қолдануға арналған. Көмек пен шешім бөлек ашылады. Барлығы 208 жаттығу; еркін жауап автоматты бағаланбайды. Аяқталу белгісі — студенттің өзін бағалауы.

На странице исходного урока сначала видны дополнительные объяснения; пример и задания можно раскрыть. Ссылка «Открыть как отдельный урок» ведёт на полную страницу. На ней есть предыдущий/следующий разбор и возврат к основной теме. В каталоге курсов появились ссылки на вводные уроки, в программах — отдельный вводный блок.

Негізгі сабақта қосымша түсіндірме көрінеді, мысал мен жаттығуды ашуға болады. «Жеке сабақ ретінде ашу» толық бетке апарады. Онда алдыңғы/келесі талдау мен негізгі тақырыпқа қайту бар. Каталог пен бағдарламада кіріспеге сілтеме берілген.

`content/*.json` содержит явно написанные тексты RU/ҚАЗ. `starts.json` — вводные уроки с семью основными файлами `examples/` и дополнительным модулем формы 1С. Сборка объединяет материалы в `dist/teaching.json`, копирует примеры в `dist/teaching-examples/`. Код и HTML экранируются; текст ответов подставляется через значение textarea, а не HTML.

`MLStore.learning` хранит отдельные отметки `completed` и письменные ответы `practice`. Ключ ответа — `path/id/1` или `path/id/2`, до 10 000 символов. Они включены в общий экспорт; старые копии без `learning` принимаются с пустыми новыми записями. Неверный идентификатор, номер задания или тип отклоняется до изменения состояния. Данные не отправляются на сервер; синхронизации между устройствами нет. При недоступном localStorage показано сообщение. Лимит импорта общего файла повышен до 16 МиБ, чтобы вместить дополнительные решения; фактическая вместимость localStorage зависит от браузера.

`MLStore.learning` аяқталу мен жазбаша жауапты бөлек сақтайды. Бір жауап шегі — 10 000 таңба. Жалпы экспортқа кіреді; бұрынғы көшірме жаңа бөлімсіз де қабылданады. Дерек серверге жіберілмейді, құрылғылар арасында автоматты синхрондау жоқ. Жалпы импорт шегі — 16 МиБ; браузер жадының нақты шегі өзгеше болуы мүмкін.

Проверки:

```sh
python scripts/build.py
python tests/verify_teaching.py
python -m http.server 8765 --directory dist
# В другом терминале / Басқа терминалда:
python tests/browser_teaching.py
```

Структурная проверка требует покрытия всех 97 тем и семи вводных, двух локализаций, уникальных объяснений, примеров и решений. Вводные Python, Go, Java и Bash действительно выполняются с проверкой вывода; 1С проверена только по материалам, установленной платформы 8.3 в среде проверки нет. Урок 1С явно описывает контекст модуля и вызова. Браузерная проверка проходит все страницы разборов и их встраивание в исходные уроки на двух языках, миграцию копий, независимость решений, повторную отрисовку и мобильную ширину. При недоступности дополнительного JSON основной урок продолжает работать.

Проверка объёма не заменяет педагогическую оценку. Содержательная проверка выполнена для арифметических трассировок, границ типов, разделения train/test, прав и согласованности операций. Разборы объясняют конкретные механизмы и не обещают, что один прочитанный текст заменит самостоятельное выполнение.
