## Как устроена практика

Каждая тема даёт несколько условий опыта и пояснение к графику. Таблица под графиком содержит численные значения. Упражнение предлагает сравнить условия и записать вывод.

Открой редактор Python в уроке, измени `lab.py` и нажми «Запустить Python». Среда Pyodide и библиотеки для импортов загружаются при первом запуске. Код выполняется в Web Worker, вывод и ошибки появляются в консоли, а графики Matplotlib и результаты опыта отображаются рядом. Файл `data.csv` из текущего урока доступен по относительному пути. Кнопка «Остановить» прекращает вычисление. Редактор загружает исходный пример при новом открытии страницы.

У каждой из 14 недель короткий `lab.py`: одна понятная задача, небольшая таблица или несколько метрик и подписанный график. Изменяемый параметр находится в начале файла. В списке «Пример для запуска» можно выбрать `experiments.py` со всеми подробными опытами урока. Переключение сохраняет правки обоих файлов до ухода со страницы. Служебный JSON подробных опытов превращается в графики и не засоряет консоль; обычный вывод и ошибки остаются видны.

Чтобы повторить расчёт в установленном Python, скачай ZIP и выполни команды в распакованной папке.

```sh
python -m pip install -r requirements.txt
python lab.py
# Все подробные опыты недели:
python experiments.py > results.json
```

Подготовленные графики используют фиксированные данные и рассчитанные сценарии. Редактор показывает результаты нового запуска отдельно. Дополнительные примеры PyTorch, YOLO и FastAPI запускаются в установленном Python по инструкциям в уроках.

## Данные и воспроизведение

Примеры используют встроенные учебные наборы или синтетические данные. CSV для кластеризации и итогового проекта лежат в [неделе 10](weeks/10/data.csv) и [практикуме](project/data.csv). Исходные наборы из учебного комплекта заменены синтетическими аналогами или встроенными данными библиотек. Результаты относятся к учебным данным и сценариям из уроков.

В практике 10 короткий пример строит PCA и t-SNE для одних и тех же 72 клиентов. Цвета обеих карт — группы KMeans по четырём стандартизованным признакам. Измени `PERPLEXITY` (5, 15, 30; строго больше 0 и меньше числа строк). В подробной пятой теме доступны три готовых условия t-SNE. Для небольшого набора используется `method="exact"`, `max_iter=500`, `init="pca"`, `learning_rate="auto"`, `random_state=42`, `n_jobs=1`; версия scikit-learn входит в зависимости лабораторной. Это учебный бюджет вычислений, а не гарантия сходимости. t-SNE исследует локальное соседство: расстояния между облаками и их площади не измеряют различие и численность сегментов. Оси имеют условные координаты и одинаковый масштаб. В `sklearn.TSNE` нет `transform` для новых клиентов; новая таблица требует нового расчёта, поэтому положение старых точек может измениться. Фиксированный seed помогает повторить результат в одной среде, но координаты могут отличаться между версиями и платформами. Подробности: [API scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.TSNE.html), [разбор чтения t-SNE-карт](https://distill.pub/2016/misread-tsne/).

`lesson.json` содержит текст RU/ҚАЗ, `lab.py` — короткий редактируемый пример, `experiments.py` — все сценарии подробных графиков, а `results.json` фиксирует их точки. В итоговом практикуме подробный расчёт по-прежнему находится в `lab.py`. Язык короткого примера берётся из `IMLEARNING_LANG=ru` или `kk` (по умолчанию `ru`); браузер передаёт текущий язык страницы. Сборка проверяет структуру и создаёт `dist/ml/index.json` и архив каждой недели. `tests/verify_ml.py` извлекает каждый архив, воспроизводит подробные опыты и проверяет короткие примеры с PNG на двух языках. `tests/browser_locale.py` проверяет оба языка, графики, самопроверку, узкий экран и повтор загрузки. `python tests/browser_ml_python.py` и `python tests/browser_ml_examples.py` проверяют реальный запуск через CDN Pyodide при запущенном локальном сайте.

Предупреждение `threadpoolctl` о `JsProxy.as_object_map()` относится к совместимости поставляемой с Pyodide библиотеки. В среде запуска отфильтрован только этот точный `RuntimeWarning` из модуля `threadpoolctl`, с восстановлением фильтров после запуска. Пользовательские предупреждения и другие диагностики сохраняются. [Исправление upstream](https://github.com/joblib/threadpoolctl/blob/master/threadpoolctl.py) использует `as_py_json()` в новых Pyodide.

Новая программа ведёт прогресс в поле `mlSemester` существующей резервной копии. Старые записи сохраняются в экспорте и при восстановлении. Для новой программы счёт идёт с первой недели, поскольку её темы имеют другую нумерацию и содержание.
