## Как устроена практика

Каждая тема даёт несколько условий опыта и пояснение к графику. Таблица под графиком содержит численные значения. Упражнение предлагает сравнить условия и записать вывод.

Открой редактор Python в уроке, измени `lab.py` и нажми «Запустить Python». Среда Pyodide и библиотеки для импортов загружаются при первом запуске. Код выполняется в Web Worker, вывод и ошибки появляются в консоли, а графики Matplotlib и результаты опыта отображаются рядом. Файл `data.csv` из текущего урока доступен по относительному пути. Кнопка «Остановить» прекращает вычисление. Редактор загружает исходный пример при новом открытии страницы.

Чтобы повторить расчёт в установленном Python, скачай ZIP и выполни команды в распакованной папке.

```sh
python -m pip install -r requirements.txt
python lab.py > results.json
```

Подготовленные графики используют фиксированные данные и рассчитанные сценарии. Редактор показывает результаты нового запуска отдельно. Дополнительные примеры PyTorch, YOLO и FastAPI запускаются в установленном Python по инструкциям в уроках.

## Данные и воспроизведение

Примеры используют встроенные учебные наборы или синтетические данные. CSV для кластеризации и итогового проекта лежат в [неделе 10](weeks/10/data.csv) и [практикуме](project/data.csv). Исходные наборы из учебного комплекта заменены синтетическими аналогами или встроенными данными библиотек. Результаты относятся к учебным данным и сценариям из уроков.

`lesson.json` содержит текст RU/ҚАЗ, `lab.py` выполняет расчёты, а `results.json` фиксирует точки для графиков. Сборка проверяет структуру и создаёт `dist/ml/index.json` и архив каждой недели. `tests/verify_ml.py` извлекает каждый архив и запускает его в отдельной папке, сверяя результаты. `tests/browser_locale.py` проверяет оба языка, графики, самопроверку, узкий экран и повтор загрузки. `python tests/browser_ml_python.py` проверяет реальный браузерный запуск через CDN Pyodide при запущенном локальном сайте.

Новая программа ведёт прогресс в поле `mlSemester` существующей резервной копии. Старые записи сохраняются в экспорте и при восстановлении. Для новой программы счёт идёт с первой недели, поскольку её темы имеют другую нумерацию и содержание.
